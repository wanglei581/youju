# 有据申报与行业助手：给园区的一页说明

**我们是谁**
「有据申报与行业助手」（简称"有据"）是一个微信小程序，由【公司全称】运营。我们是第三方，整理政府网站公开发布的信息；不是政府平台，不代办申报。联系人：【联系人姓名】，【工作电话或邮箱】。

**数据从哪来**
- 国家部委和 28 个省的科技、工信等部门网站公开发布的申报通知和公示名单。市、区目前只收了广州、苏州和青岛黄岛区，浙江、广西、甘肃还没有。
- 每条都附政府原文链接。截止日期写明是人工核对过的，还是机器从原文里摘出、未经人工核对的；一切以原文为准。
- 公示名单从 2026 年 7 月开始收录，只收能读出企业名称的。

**能给园区的两样东西**
1. **园区企业上榜汇总**：园区给入驻企业的全称名单，我们出一张表，写哪些企业上了哪份已收录的名单、原文链接，可用于年底统计。只写名单上有什么，不评价企业，也不判断能不能申报。
2. **本省未来 14 天截止的清单**：一份只放截止日期已人工核对的，可以直接转进企业群，末尾写明出处；另一份带机器摘录的日期，只给专员自己看。转不转、多久转一次，由园区定。

**不收费**
上面两样不收费，也不用签任何东西。小程序现在免费使用；以后如果有收费的功能，会在小程序里写清楚，用不用由使用的人自己决定，不会自动扣钱。

**做这两样东西，不收集企业员工的个人信息**
- 名单只要企业全称，不要联系人、电话和员工信息。
- 名单只在园区和我们之间直接传，不转给任何人，不存到服务器上，交表当天删除我们本机的文件。
- 我们不进园区的企业群，不在群里发东西，也不用园区的名义对外宣传。
- 企业的人自己用小程序时，按小程序里的《隐私保护指引》处理：检索、查名单不用登录；用关注、纠错等功能要用微信身份登录，不要手机号。

**随时可以停**
园区说一声"停"，我们就不再发清单、不再联系。给过的名单在交表当天已经删除，没有需要收回的东西。
