# 推广与商业化方案 v1（2026-10-03）

> 创始人 10/3 定的方向：**免费使用、有额度；额度用完后按需求选订阅或按次付费**。Codex 联网调研起草（第一至五节），agy 合规把关（第六节），Claude 核对：竞品价格在官网价格页复核过（399 / 599 / 1099 元个人版、16888 / 36888 元集团版，10/3 本机访问）；其余渠道效果、转化都是"待验证"的假设。**价格是试价区间，访谈后由创始人定；取得 ICP 经营许可证之前不收款、不预售。**
>
> 和《定价与套餐方案 v1》的差别：本方案建议先用更低的档位试（机构 50 家年卡 1980–7800 元，原草案 7800 元；园区轻量合同 5000–10000 元，原草案 28800 元起），理由是基础查询免费、付费能力比成熟竞品少。两份都保留，访谈时拿两种价位问。

定位：第三方整理政府公开通知和名单，非政府平台、不代办。先验证顾问的多客户需求；企业免费，园区带企业。

**2. 用起来并留下**

首次30秒：选地区或输入企业全称→看到一条相关结果→打开正文；随后引导关注，提醒授权可跳过。未覆盖地区明确提示，给原文入口。

第一周用真实项目查名单、导出。回访入口是每周截止清单、已关注项目临近截止/核对后的变更、名单更新及工具任务完成。按需选择提醒时间，合并同日消息；一次授权对应一次通知，不承诺连续推送。[腾讯云说明](https://cloud.tencent.com/document/product/1301/103770)

**3. 免费额度与付费**

额度为收费阶段建议；首版基础免费。ICP经营许可证取得前不收款、不预售。

永久免费：搜索筛选、详情正文、日历、人工核对截止雷达、查名单与看板、关注微信提醒、基础Excel/Word导出。

|功能|免费建议|

|多客户跟进|10家活跃客户；新生成1次/日、5次/月，查看编辑免费|
|解读＋材料清单|2次/日、10次/月|

|月度PPT|1份/月、≤10页|

日/月上限同时生效；成功才扣，同结果重复下载不扣。AI登记及类目审核完成后上线，入口再从“工具”改为“AI顾问”。

触顶提示：“本月已用5/5次，×日恢复。仍可查原文、下载已有结果；临时需求选按次，经常使用选套餐。”展示总价、家数、次数和有效期。

试价：解读10次包59–199元，PPT49–99元/份；自动名单比对≤100家99–299元/次，不含人工咨询。单人顾问10家年卡399–1099元；机构50家/3账号年卡1980–7800元；园区≤200家轻量年合同5000–10000元。单人/机构/园区每月含工具20/50/50次、AI20/100/100次、PPT1/2/2份；季卡约年价1/3，超额明码加购。

依据：snap中的查策网个人399/599/1099元、集团16888元/年，已在[官网价页](https://www.chace-ai.com/cooperation/)复核。基础查询免费，付费能力少于成熟竞品，先试低档，不照搬草案高价。

机构先按次验证，再季卡、年卡；园区先免费带企业，再按企业规模签合同；企业个人保持免费，偶发AI买按次包，独立顾问选单人卡。全部预付、不自动续费，到期提醒，数据可导出删除。功能、许可齐备后报价，访谈和成本定价。

**4. 每周只看5个数**

1. 新增目标账户数：机构/园区，按上述来源拆分。
2. 首次激活率：新用户中完成查询并打开相关结果的比例。
3. 次周留存率：上周激活者本周再次查询、导出或完成工具任务的比例。
4. 付费需求人数：触顶后主动选择按次或套餐；拿证前只记意愿。
5. 实收收入：按次与套餐合计；拿证前为零。

**5. 三个最大风险**

- 信息错误伤信任：关键字段人工核对，附原文、口径和核对时间；变更复核后提醒，未命中不等于未入选。
- 免费够用、收入不足：访谈验证多客户省时价值；不先做重园区定制。控制周投入及AI预算，低效渠道停做。
- 手续或客户数据问题：按既定许可、登记顺序上线；客户名单授权上传、隔离保存、可删，不进入公开分享；AI输出标识并公示模型信息。[网信办公告](https://www.cac.gov.cn/2024-04/02/c_1713729983803145.htm)

## 6. 合规把关（agy）

### 1. 推广合规
- **诱导违规**：“分享得额度”“关注公众号才给导出”属微信平台严厉打击的诱导分享与诱导关注，极易被封接口或下架。合规做法：导出直接提供（或发邮箱），公众号仅作为“可选的订阅提醒通道”。
- **提醒内容与资质**：发布政策截止提醒需显著标注“非官方平台，信息仅供参考，以官方正式公告为准”，杜绝冒用政府公信力或误导公众。
- **导出物与分享卡片**：附带小程序码必须展示版权与免责声明，卡片文案需客观真实，严禁煽动焦虑或诱导裂变。
- **广告法红线**：严禁使用“最高级、最佳、唯一、首选”等绝对化用语；严禁宣传“保过、稳拿补贴、100%获批”等保证性、承诺性表述。

### 2. 收费合规
- **前置资质与规则**：小程序内收款必须具备ICP经营许可证、微信商户号、发票开具及退款机制；支付前必须醒目标注“单次预付、不自动续费”。
- **iOS虚拟支付限制**：微信严禁iOS端销售虚拟商品（额度/报告/会员均属此类），在iOS内直接收费或引导外链支付会被平台严重违规处罚。
- **对公转账优先**：**完全可以且建议优先推行**。针对机构客户走线下/电子对公合同、银行转账并开票，后台人工充值额度，合法合规且避开iOS虚拟支付限制。

### 3. 额度设计合规
- **明码标价**：收费页清晰公示额度计费单价、扣减规则及使用期限。
- **清零与退款**：“过期清零且不退款”属免除自身责任的无效格式条款（霸王条款），极易引发客诉。到期前须推送提醒，未消费额度建议支持延期或按规则退款。
- **未成年人**：服务协议明确仅限成年企业从业人员使用，设置防误充退款通道。

### 4. 须先咨询律师或主管部门的事项
1. 爬取、整理政府公开信息并商业化销售的数据合规与不正当竞争风险（待核实）。
2. 针对B端工具在微信iOS生态的最新支付规避与合规边界（待核实）。
3. ICP经营许可证的具体业务范围核定要求（待核实）。
4. 上线“AI顾问”前的生成式AI算法备案及监管登记流程（待核实）。
