# 素材来源与许可

小程序里用到的第三方界面素材：从哪里来、什么版本、什么许可、怎么生成。加新素材时在这里补一行。

## TDesign 小程序组件

| 项目 | 内容 |
|---|---|
| 包名 | `tdesign-miniprogram`（腾讯 TDesign） |
| 版本 | 1.17.0（`apps/miniapp/package.json`） |
| 许可 | MIT，Copyright (c) 2021-present TDesign |
| 来源 | npm 包；微信开发者工具"构建 npm"后生成 `miniprogram_npm/`（不在 git 里） |
| 用到的组件 | 只有弹层 `t-popup`（搜索页的筛选面板，连带它的遮罩 `t-overlay`） |

`t-popup` 内部登记了 TDesign 自己的 `t-icon`，只在开了自带关闭按钮（`close-btn`）时才渲染。我们不开这个按钮，关闭按钮用自己的图标组件放在弹层内容里，所以它的 `t-icon` 不渲染。它的样式里仍然声明了指向 TDesign 网站的字体，但没有元素用这个字体，小程序不会去下载。测试（`apps/miniapp/tests/icon.test.js`）检查 `t-popup` 没有开 `close-btn`，并且除弹层外没有登记别的 TDesign 组件；以后要加 TDesign 组件，先确认它不用在线图标字体。

## 图标

| 项目 | 内容 |
|---|---|
| 来源 | TDesign 图标字体 `tdesign-icons` 0.4.5 的 `t.ttf`（https://tdesign.gtimg.com/icon/0.4.5/fonts/t.ttf，就是 `t-icon` 原来在线加载的那份） |
| 原字体 sha256 | `c121c5265a8ebb0a9e267d18a97754312a344869efcd5a1f0b2756995b2806cc` |
| 许可 | MIT，Copyright (c) 2021-present TDesign；许可全文写在生成的 `components/icon/index.wxss` 开头 |
| 用法 | 本地组件 `apps/miniapp/components/icon/index`，在各 json 里仍登记为 `t-icon`，页面写法不变：`<t-icon name="search" size="36rpx" color="#86909C" />` |
| 字体 | 只保留 `tools/icons/icons.txt` 里列出的 30 个字形，压成 woff（3760 字节），以 base64 内嵌在组件样式里（样式文件约 8.7 KB），不从网络加载 |

字形和编码的对应关系取自 TDesign 小程序组件的 `miniprogram_npm/tdesign-miniprogram/icon/icon.wxss`（`.t-icon-xxx:before{content:'\E00D'}`），生成时再和字体里的字形名逐个核对。

首页"截止雷达"入口用 `hourglass`（沙漏：截止日期临近），和"申报日历"的 `calendar` 区分开。

### 加图标、重新生成

1. 在 `tools/icons/icons.txt` 里加一行 TDesign 图标名（图标名在 TDesign 图标网站或上面的 `icon.wxss` 里查）。
2. 准备好 `miniprogram_npm`（微信开发者工具"构建 npm"，或从已构建的目录复制）。
3. 在临时目录建 Python 虚拟环境装 fonttools（不要装到系统 Python），在仓库根目录运行：

   ```sh
   python3 -m venv /tmp/icons-venv
   /tmp/icons-venv/bin/pip install fonttools
   /tmp/icons-venv/bin/python tools/icons/build_icons.py --font <t.ttf>   # 不给 --font 就从上面的地址下载
   ```

4. 运行 `cd apps/miniapp && npm test`：测试检查代码里用到的图标都在字体里、生成的样式和 `icons.txt` 一致、小程序代码里不出现 `tdesign.gtimg.com`。

同样的输入每次生成同样的文件；原字体换了版本时，sha256 会变，要在这里同步更新版本和 sha256。
