# 小程序原型 v1（2026-09-26）

「有据」微信小程序免费版（R1）的可点击原型，9 个页面：找答案（首页）、搜索结果、筛选、文件详情、申报日历、查名单、关注、文件、我的。

- **在线查看：** [有据小程序原型 v1](https://claude.ai/artifact/46cN5cikNz91TLR5LmJof3)（创始人账号可打开；要给别人看，需要先在页面的"分享"里开放）。
- **本目录：** 原型源文件的存档。每个 `.dc.html` 是一个页面，`canvas.json` 记录页面在画布上的位置。源文件依赖画布运行环境，直接用浏览器打开显示不完整，以在线版本为准。
- **数据：** 页面上的文件标题、发文机关、日期、文号、截止时间、统计数字都来自 2026-09-26 的真实抓取和原文核对，不是虚构的示例。
- **状态：** 等创始人确认（Issue #11）。确认前不写小程序界面代码（见[开发流程](../../开发流程.md)）。

设计取向：以文字排版为主，像一份整理好的文件。标题用思源宋体，界面文字用思源黑体；底色为暖白纸色，正文墨色，只有截止时间和品牌印章用朱红。不用渐变、表情符号和彩色图标块。
