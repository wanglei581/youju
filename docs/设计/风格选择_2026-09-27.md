# 设计风格选择（2026-09-27）

- **状态：** 团队建议，等创始人确认。确认后按本文的 v2 规范重做原型 9 个页面。
- **做法：** 同一个首页、同样的真实数据，做成四种风格（图在 [风格对比](./风格对比/)，也在[原型画布](https://claude.ai/artifact/46cN5cikNz91TLR5LmJof3)第三行）。Codex、agy、Grok 三名成员各自独立评审，Claude 汇总；方向一致，细节有分歧，由设计主审 Codex 看过实际效果图后定稿。各成员的原始意见见 [评审原文](./风格对比/评审原文/)。

## 四种风格和结论

| 风格 | 参考应用（uinotes.com） | 结论 |
|---|---|---|
| A 公文纸（原型 v1） | 微信读书、网易蜗牛读书 | 保留它的排版质感：细线分隔、克制的配色、紧凑的条目 |
| B 效率工具 | 飞书、ima、腾讯会议 | 采用它的信息结构和操作：搜索优先、状态一眼可见、勾选导出；不要大留白和满屏卡片 |
| C 企业查询蓝 | 企查查 | 不用：蓝色通栏和彩色宫格接近政务门户，也像企业查询换皮；运营位盖住截止和出处 |
| D 资讯媒体 | 36氪、虎嗅 | 不用：文章流有被当作新闻信息服务的审核风险（agy 判断，需要什么资质待核实）；还会把原文改写成标题，违背"以原文为准" |

**推荐：A 的排版质感 + B 的信息结构和操作。** 三名成员独立评审得出同一方向，Claude 也同意。

## 已定的分歧

| 问题 | 决定 | 理由 |
|---|---|---|
| 朱红方形"据"印章 | 去掉，改为黑体"有据"字标，旁边用靛蓝小字"每条都有出处" | 方印加纸色容易被当成公章、红头文件（agy、Codex） |
| 宋体用在哪里 | 只用于文件详情页 20px 以上的文件标题；首页和列表全部用黑体 | 列表要快速扫读，不少用户 35–55 岁 |
| 朱红用在哪里 | 只提示临近的截止时间，不做品牌色 | 避免"官方""警告"感 |
| 状态文字 | 写"公示"和"正式公布"，不写"公示中" | 无法确认公示期是否还没结束（Claude） |
| 日期 | 列表写完整日期 2026-09-24；截止写"10月18日截止 · 剩22天" | 名单常跨年，年份不能省 |

## v2 设计规范（Codex 起草，Claude 按团队意见调整）

| 项目 | 规范 |
|---|---|
| 颜色 | 页面 #F7F6F2；列表和输入框 #FFFFFF；正文 #1C252B；次级文字 #59636B；弱信息 #79838A（不用于来源和日期）；分隔线 #D9DED7；主操作和链接 #254A73；截止警示 #B42318 |
| 字体 | 全局思源黑体，文件详情标题用思源宋体。页标题 22/30、600；列表标题 16/24、600；正文 14/22、400；标签和辅助信息 12–13/18、500；统计数字 28/34、600；数字用等宽 |
| 布局 | 左右留白 16px；间距 4、8、12、16、24、32px；列表行内边距 16px，行间 1px 分隔线；输入框圆角 10px，按钮 8px，标签 4px；可点区域至少 44×44px |
| 列表行 | 第一行：类型标签、地区、状态，截止靠右；第二行：标题，最多三行；第三行：发布机构和日期，右侧"官方原文 ↗"单独可点 |
| 标签 | 高 24px；类型用浅底深字；"公示"虚线框、"正式公布"实线框，都写文字，不只靠颜色 |
| 控件 | 主按钮靛蓝底白字；次按钮白底靛蓝边；按钮高 44px；搜索框高 48px，带清除键，聚焦后显示最近搜索 |
| 导航与空状态 | 底栏四项：找答案、关注、文件、我的；图标 22px 线性，选中用靛蓝。空状态写清是"没有结果""还没关注"还是"该地区暂未覆盖"，各给一个下一步操作 |
| 勾选导出 | 长按或点"选择"进入多选；底部显示"已选 X 条 · 导出"，零条时不能点；导出前选 Excel 或 Word，并说明包含标题、关键字段、状态、日期和原文链接；生成后进入"文件" |

## 各页面对标（暂定）

目标是先达到真实上线产品的完成度。只学完成度和交互惯例，不照搬对方的标志、图标和品牌色。**以下对标还没有对照截图核实，是暂定的**，核实后再定稿。

| 页面 | 对标 | 学什么 |
|---|---|---|
| 首页 | 企查查 | 搜索优先、常用任务直达、结果密度 |
| 搜索结果 | 网易有道词典 | 关键词突出、相关信息紧跟结果 |
| 筛选 | 猎聘 | 多条件选择、已选条件可见、一键清除 |
| 文件详情 | 微信读书 | 长文层级、舒适行距、定位和返回 |
| 申报日历 | 腾讯会议 | 日程扫描、日期切换、临近提醒 |
| 查名单 | 企查查 | 精确查询、字段对照、状态识别 |
| 关注 | 飞书 | 更新聚合、未读提示、批量处理 |
| 文件 | 夸克网盘 | 导出记录、格式识别、查找和管理 |
| 我的 | 微信读书 | 简洁的账户结构、设置和说明好找 |

uinotes.com 的应用截图要登录才能看，团队目前只能看到应用名单，对标依据是成员对这些应用的了解。创始人在 Claude 的内置浏览器里登录后，团队可以逐页对照截图核实。
