创始人确认"风格 C 精修版"后（[决策记录 D-014](../../决策记录.md)），按统一规范重做的 9 个页面：首页、搜索结果、筛选、文件详情、申报日历、查名单、关注、文件、我的。

- **在线查看：** [有据小程序原型 v2](https://claude.ai/artifact/46cN5cikNz91TLR5LmJof3)（第一、二行是 v2 页面；第三行是风格对比）。画布默认只有创始人能打开，要给别人看，先在页面的"分享"里开放。
- **效果图：** [效果图](./效果图/)，按各页默认状态渲染；`Calendar_点选日期.png` 是日历点选 10 月 18 日后的状态。
- **源文件：** `*.dc.html` 是画布上的页面，可以点：首页标签、筛选、日历范围和点选日期、订阅提醒、复制原文链接（会把原文网址写入剪贴板）、勾选协议后才能登录。`canvas.json` 是画布布局。
- **生成脚本：** `生成脚本/ds.py` 是设计规范和公共组件（颜色、字号、导航栏、底栏、标签、列表行、出处说明条、复制原文链接），`生成脚本/pages.py` 用它拼出 9 个页面。改规范只改 `ds.py`，重新生成即可保证各页一致：

```bash
cd docs/设计/原型v2/生成脚本 && python3 pages.py .. static && ./render.sh Main:1790 Search:1350 Filter:844 Detail:1600 Calendar:1345 Lists:1240 Follow:1430 Files:900 Me:900
```

  页面写到上一级目录；预览 HTML 和效果图在 `生成脚本/static/`（不入库），确认后复制到 `效果图/`。渲染需要本机装有 Chrome。

- **数据：** 文件标题、发文机关、日期、文号、截止时间、统计数字来自 2026-09-26 的真实抓取和原文核对。原型里的"今天"是 2026 年 9 月 27 日（周日），剩余天数按这一天算。导出记录的文件大小、时间是示例。
