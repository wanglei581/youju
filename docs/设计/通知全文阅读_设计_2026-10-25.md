> 状态：创始人 10/25 晚已按推荐定（D-097，原话"4 件都按推荐定"）。
> 做法：同一份材料（现状、线上实测、约束）交给 Codex（gpt-6-sol）、agy（gemini-3.8-flash-high）、Grok（grok-4.7-build-fast）和 Claude 各自独立出方案、互相看不到；Claude 汇总后三方交叉审一轮：采纳的意见已改进本稿，没采纳的和各方分歧写在文末"四方分歧和取舍"。工作稿在计划文档"通知全文怎么看全（D-097 已定）"一页。

起因：创始人 10/25 问"抓取的数据和内容打开通知内容看，是不是看不到完整的内容？这个抓取到的文件是不是要可以看到完整的内容"。

**结论：** 很多通知在小程序里确实看不全，最大的缺口是附件。抓到的政府通知和附件应在小程序里给全部文字，给不全的地方一句话说清缺什么、为什么。

## 一、现在为什么看不全

10/25 晚用小程序自己的接口只读抽查线上最近一个月发布的 500 条（申报通知 200、政策 100、名单 100、其他 100）。按影响从大到小：

| 原因 | 线上实测 | 怎么修 |
| --- | --- | --- |
| 附件文字还没补 | 点开申报通知、政策的 70 个附件：69 个"附件文字正在准备"，1 个格式不支持，能读 0 个。附件文字原来只在每天 10:15、23:30 的附件副本任务里顺带取，10/25 上线后还没补过 | 存量一次补完（创始人在 admin 手动跑）；每轮抓取当轮补（#366） |
| 一部分通知没正文 | 申报通知 16%、政策 20% 没正文，集中在广东科技厅 22 条、重庆经信委 18 条；重庆、青海等用新规则已能取到全文，是旧正文没重抓 | 重抓旧正文（创始人 10/25 已同意）；广东科技厅加网站规则（#364）；短通知照常显示 |
| 两类正文一律不给 | 资讯与指南、其他约占全部 2325 条的三分之一，里面也有办事指南、政策解读 | 个人事项类不给，政府指南、解读放开 |
| 能读的也像没抓全 | 82% 的申报通知正文超过 600 字，详情页截在半句；"展开全文""站内阅读全文""站内阅读"三个入口分不清 | 详情页给开头 + 一个"阅读全文"；阅读页标页数、接着读附件 |
| 只有纯文字 | 网页表格被拆成一行行字，图片不显示；遮掉电话的地方写"（电话见原文）"，像在叫人去原网站 | 表格按表格显示（第二步）；遮挡处改"这里隐去了电话" |

线上全量（10/25 20:19 创始人在 admin 跑的只读统计）：待取文字的附件 927 个（申报通知近 180 天 819 个、政策近 90 天 108 个，能读 0 个），压缩包等不支持的 16 个；带网页字样的正文 514 份，分布在 33 个来源；按新脱敏规则要重新打开的 849 份，其中显示会变的 115 份。

## 二、"看全"指什么

| 内容 | 怎么给 |
| --- | --- |
| 通知正文（申报通知、政策、名单类通知的说明部分） | 全部文字。身份证号、个人手机号、银行账号照旧遮掉，遮掉处写"这里隐去了电话"之类 |
| 申报通知、政策的附件 | 全部文字；表格按"列名：内容"显示，可横滑 |
| 图片、扫描页、公章 | 暂不显示原图：图里的个人信息没法逐字遮，公章图有被仿造的风险。写明缺几张、几页（第二步做计数） |
| 名单 | 不变（D-088、D-092）：通知文字能读，名单只给按企业名称查到的那一行和表头 |
| 资讯与指南、其他 | 招聘、考试、职称、任免、表彰个人、救助、处分等个人事项不给，按标题词表判断（词表在代码 `PERSONAL_MATTER_WORDS`）；其余政府文件（办事指南、政策解读、会议通知等）给全文，同样脱敏（D-097 ②）。这两类的附件放第二步 |
| 原网页已打不开的 | 维持现状：正文不给，只留要点和截止；先统计失效原因再议 |
| 非政府来源的解读、报告 | 只给题录和 200 字以内摘要（章程红线，不变） |

依据：[《著作权法》第五条](https://www.gov.cn/guoqing/2021-10/29/content_5647633.htm)，国家机关的决议、决定、命令和其他具有行政性质的文件不适用该法；但政府网站上的署名解读、研究报告不一定属于这类，要按类核定。[《个人信息保护法》第十三条第一款第（六）项、第二十七条](http://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)：已合法公开的个人信息只能在合理范围内处理，对个人权益有重大影响的要取得同意，所以个人事项类不给。两条原文已打开核对。

## 三、页面怎么改（D-097 ①）

详情页用来判断要不要报，阅读页用来读完；入口只留一个名字"阅读全文"。

### 详情页

1. 标题区 → 截止 → 要点，和现在一样。
2. 正文卡顶上一行写这条能读到什么，如"正文约 3200 字 · 附件 3 个，2 个能读，1 个扫描件暂不能识别文字"。
3. 正文先显示开头约 3 段，在段落末尾停，写"下面是开头，全文约 N 字"；正文不满一屏就全部显示，写"全文如下"。
4. 正文下面一个"阅读全文"，底栏主按钮也叫"阅读全文"，两处去同一页。正文已在详情页全部显示时：有能读的附件，两处都叫"阅读附件"；没有能读的附件，两处都不显示。只有附件能读时也叫"阅读附件"。去掉"展开全文"和中间单独的大按钮卡；正文和附件都读不了时两处都不显示。
5. 附件清单紧跟正文，每个附件直接写状态：能读的显示"阅读"可点；读不了的灰色、不能点，写原因。状态和阅读页用同一套判断，不用"有没有副本"冒充"能不能读"。
6. 没正文时分情况：有附件的（不管是网站上本来就只放附件，还是网站正文取不到），写"这份通知的内容在附件里"，附件提到这句下面；没有附件的，写"这个网站的正文还取不到"。
7. 出处只写来源网站名称、发文机关、日期，不再写网址（网址文字有被审核认为引导外跳的风险）。

### 阅读页

- 顶上：标题、发文机关、日期；目录"正文 · 附件 1 · 附件 2"，读不了的附件在目录里也写状态。
- 页码写"正文 第 2 页 / 共 5 页""附件 1 第 1 页 / 共 3 页"；再进来时写"从你上次读到的第 N 页继续"，并给"从开头看"。
- 正文末页写"正文完"，下面接"接着读附件 1：××"。
- 有扫描页的，最后写"能显示的文字到这里。另有 N 页扫描件，暂不能识别文字"，不写"全部读完"。
- 内容更新时提示"正文已更新"，回到第 1 页；页数和续读位置跟着内容版本走。

### 每种情况写的一句话

| 情况 | 页面上写 |
| --- | --- |
| 正文已在详情页全部显示（不满一屏） | 全文如下 |
| 只显示了开头 | 下面是开头，全文约 N 字 |
| 没正文、有附件 | 这份通知的内容在附件里 |
| 没正文、也没有附件 | 这个网站的正文还取不到 |
| 附件是扫描件 | 扫描件，暂不能识别文字 |
| 附件格式不支持（压缩包、ofd 等；wps、et 能读，只取文字） | 此格式暂不能在小程序内阅读 |
| 新附件刚收到、文字还没取 | 新附件，一般半天内可读（灰色、不能点） |
| 名单类通知 | 正文如下，名单请按企业名称查询 |
| 个人事项类（招聘、考试、职称、任免等） | 含个人信息，不在小程序内展示全文 |
| 遮掉的号码 | 这里隐去了电话 / 证件号 / 银行账号 |
| 正文里的图片（第二步） | 这里有 N 张图片，暂不能显示 |
| 表格暂按行显示（第二步） | 这里原是表格，暂按逐行文字显示 |

页面上不再出现：已脱敏、见原文、摘录、收录不足、请稍后重试、正在准备。

## 五、怎么衡量、什么时候提审（D-097 ④）

达到下面的门槛再提审：审核员体验路径里有"在详情里点附件，文字在小程序里显示"这一步。下面的数字每天自动算，写进运维日报；分母都含失败、处理中和不支持的。

| 指标 | 口径 | 10/25 | 提审门槛 |
| --- | --- | --- | --- |
| 正文能读率 | 近 30 天申报通知 + 政策里，正文文字能读的份数 ÷ 全部 | 抽样 248/300 = 82.7% | ≥ 90%，争取 95% |
| 附件能读率 | 应能读的附件里文字已能读的个数 ÷ 全部；另报最老一个等了多久 | 0% | 没有等了超过一轮的 |
| 整条能读率 | 正文和应能读的附件都能读的份数 ÷ 全部；有扫描页、图片的单列，不算整条能读 | 未统计 | ≥ 75% |
| 失败网站 | 失败最多的 10 个网站和原因 | 广东科技厅、重庆经信委居前 | 每周看一次 |

提审前还要：这 300 条固定样本复测一遍；提审演示用的 2–3 份通知必须是近 180 天的申报通知、附件是能取文字的格式并逐份点开确认；安卓真机按 Grok 写的检查清单走一遍。达不到先不提审。

## 六、分几步、不做什么

1. **第一步（提审前）**：附件存量补齐；新附件当轮补；重抓旧正文；广东科技厅规则；第三节的页面改动；资讯与指南、其他放开正文（D-097 ②）；政策附件文字保留 2 年（D-097 ③）；每日数字。每个 PR 都在开发者工具里连真实数据把过审版和完整版各走一遍，Grok、agy 审过没有必须改的，再由协调窗口合并上线。
2. **第二步（提审后马上）**：关键词定位和附件关键句（D-089 已定）；正文表格；图片和表格的说明句；资讯与指南、其他类的附件。
3. **以后**：扫描件和图片识别文字、压缩包、AI 汇编（D-082，第二版）。

不做：跳浏览器、调第三方应用打开、给复制网址；整份展示名单；显示扫描件和公章原图；首发用 AI 代读；把"后台有副本"当成"用户能读"。

## 七、创始人定的 4 件（D-097）

10/25 晚创始人回复"4 件都按推荐定"：

| 事项 | 为什么推荐 |
| --- | --- |
| 1 页面按第三节改：详情页给开头 + 两处同名"阅读全文"、附件直接写状态、阅读页页码和续读、统一说法、去掉 200 字门槛、遮挡处改"这里隐去了……"、出处不写网址 | 第一次用的人不再以为没抓全；审核员不会点进空页面 |
