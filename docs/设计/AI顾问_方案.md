# AI 顾问：方案 v2（R2）

> 2026-09-29。创始人要求在小程序里加"AI 顾问"：上传图片或文字分析，查资料库、深度思考、联网检索找答案；结果导出 PDF、Word、Excel、PPT；内置可选的"技能包"。v1 由 Grok（联网查官方原文）、Codex（技术）、agy（合规）各出方案、Claude 汇总；v2 按三方找漏洞的意见改（第十二节）。待创始人拍板。

## 一、定位：和政府免费平台有什么不同

政府的惠企平台（如长春、中山、深圳的政策计算器和解读助手）已经免费提供单个地区的政策解读、匹配和推送（Grok 调研，链接见第十二节）。我们不去重复，只做它们做不到的三件事：

1. **跨地区**：一处查全国 28 个省和国家部委的通知和名单。
2. **多客户批量**：咨询顾问一次处理几十家客户（批量查名单、批量跟进在报项目）。
3. **带出处、能转发的交付物**：每个结论都有原文出处，导出的文件可以直接发给客户或领导。

## 二、给谁用

| 用户 | 最想要的 |
|---|---|
| 申报咨询顾问、科技服务机构（**主要付费用户**） | 几十家客户谁上了名单、谁该报哪个项目、哪天截止、卡在哪个条件 |
| 园区、孵化器的企业服务人员 | 园区企业和在报项目的对照表 |
| 企业申报专员 | 一份通知讲了什么、要准备什么、和去年有什么不同 |

## 三、技能包（Skill）

**一个技能包 = 一份受限的配置**（不能写任意代码）：适用问题、输入表单、步骤、允许用的工具（白名单：资料库检索、名单查询、文字识别、政府网站联网检索）、输出模板、校验规则、测试集、步数/令牌/费用上限、版本号（带签名）。新增或修改先在测试环境跑测试集，达标后灰度上线，可一键回退。**用户默认从技能包进入**；通用提问框也只给带出处的解读，不下"能不能报"的结论。

**上线顺序：**

| 批次 | 技能包 | 是否需要生成式 AI | 产出 |
|---|---|---|---|
| **第一批（不用 AI，可先上）** | **名单比对**：上传客户名单（Excel，企业名称或信用代码），查每家上过哪些公示/公布名单 | 否（数据库查询） | Excel 明细 + 汇总 |
| **第一批** | **多客户在报项目跟进表**：选客户所在地区和行业标签，列出未截止的申报通知、截止日期（只用核对过的）、支持方式 | 否（用 D-034 的核对过的字段） | Excel |
| 第二批（登记后） | **政策解读和材料清单**（合并）：一份通知的要点、谁能报（原文摘录）、材料清单，每条带出处 | 是 | Word / PDF |
| 第二批 | **条款对照**：把企业情况（手填或上传）和通知条件逐条对照，只写"已满足/需确认/未提供"和依据，不下结论 | 是 | Word + Excel |
| 第三批 | **与去年差异**：同一类项目今年和去年通知的条件、截止、支持方式对比 | 是 | Word |
| 第三批 | **月度政策汇报 PPT**：按地区、行业、月份，选模板 | 是 | PPT |
| 暂不做 | 申报书初稿审校（低频、容易被期待代写） | — | — |

**第一批两个技能包不用生成式 AI**，只是查数据库和导出表格，不需要等网信办登记，可以在 R1 之后很快上线（R1.5）。

## 四、页面（小程序）

1. **入口是右下角圆形悬浮按钮（D-040，2026-10-03，取代"首页加入口"）：**
   - 放在首页、搜索结果、文件详情、申报日历、截止雷达、查名单、名单看板、关注；协议页、表单页、键盘弹起、批量勾选导出时不显示。品牌蓝圆钮，不闪动；避开底部标签栏、详情页底部操作条和安全区，不挡"加载更多"。
   - 带上下文：在文件详情页点进去默认处理这份通知（顶部显示标题，可清除）；在搜索页带当前筛选条件。
   - 点进去是**整页**（不是半屏、不是开放式聊天）：选功能 → 出结果 → 结果下面可追问。第一屏：政策解读与材料清单、条款对照、和去年比变了什么（这三个用 AI）；名单比对、多客户在报项目跟进表（归在"数据工具"，不打 AI 标签）。
   - 不做成孤岛：结论带原文引用、点了回到详情对应段落；提到的截止可以设提醒或关注；导出进"文件"页；截止日期、支持方式只用人工核对过的。
   - **分期：** 网信办登记和微信"深度合成 > AI 问答"类目办好之前，按钮叫"**工具**"，只有名单比对和跟进表（R1.5），页面不出现"AI"字样；办好后改名"**AI顾问**"，先上"政策解读与材料清单""条款对照"（R2），"和去年比"第二步。AI 功能作为单独版本提审，不用"审核时藏起来、过审后打开"的做法（微信禁止）。
2. 填表单或上传 → 显示进度 → 完成后在"我的文件"里；生成较慢时用微信订阅消息通知"文件已生成"。
3. 第二批起的 AI 回答卡片：顶部"AI 生成，仅供参考，以原文和主管部门解释为准"；引用列表可点回原文；导出按钮。
4. 第一次使用上传功能前，单独同意《工具使用说明》（原称顾问服务说明；隐私、保存期限、免责）。

## 五、技术架构

1. **任务**：提交即返回任务编号；后台用持久队列和状态机（排队 → 处理中 → 完成/失败/已取消），每一步有超时、可重试、幂等（同一请求不重复扣额度），失败进死信并提醒；小程序查询进度的间隔从 3 秒逐步拉长到 15 秒，完成后可用订阅消息通知。
2. **上传**：小程序直传到对象存储的**隔离暂存区**（只有后台能读、按用户和机构隔离、加密）；后台先做文件类型和病毒检查，再解析（Excel 表格、PDF/Word 文字、图片文字识别），解析出的文字和图片分块过微信内容安全接口，然后隐去身份证号、手机号等，最后才送模型。
3. **资料库检索**（第二批）：正文按段落切块，存快照指纹和段落位置；关键词 + 向量两路检索，按地区、年份、类型过滤；回答里的每条引用必须能定位到段落。冲突时的优先级：核对过的字段 > 通知原文 > 联网网页。
4. **联网检索**（第二批）：只允许政府网站域名，经后台代理访问（防止访问内网等攻击），网页内容当作数据、不当作指令（防提示注入），引用给出链接和日期。
5. **导出**：Excel（openpyxl，单元格里以 = + - @ 开头的内容转义，防公式注入）、Word（python-docx/docxtpl）、PDF（由 Word 或 HTML 转）、PPT（python-pptx 套母版，第三批）。每种格式有固定的渲染回归测试；生成后自动检查显式和隐式标识都在；存对象存储，下载地址有效期短。
6. **名单比对口径**：企业名称按查名单同一套规则归一（全半角括号、空格），信用代码精确匹配；输出每行的匹配结果（命中/未命中/多个同名），附数据版本（资料库更新时间）；同一客户多次上同一名单去重；导出行数和数据库查询结果逐行核对。
7. **审计**：任务、工具调用、引用、导出都记日志（沿用 D-028）；缓存按机构隔离，不会串数据。

## 六、合规（已核对官方原文，2026-09-29）

| 事项 | 要求 | 做法 |
|---|---|---|
| 网信办登记 | 调用已备案大模型向公众提供生成式服务的，向属地网信办办理登记，上线后公示模型名称和编号 | 第二批开发同时，先向省网信办咨询；**预留 1–2 个月** |
| 算法备案、安全评估 | 《生成式人工智能服务管理暂行办法》第十七条：具有舆论属性或社会动员能力的要做 | 提前问网信办和律师我们是否属于；按需要准备材料 |
| 小程序类目 | "深度合成 > AI问答"，要技术提供方（阿里云百炼）的算法备案和双方合作协议；生成内容显著位置标"AI生成" | **顺序：先拿登记凭证 → 再申请类目 → 再提审第二批** |
| 标识 | 《人工智能生成合成内容标识办法》：显式标识 + 文件元数据隐式标识 | 页面和每种导出文件都做，自动检查 |
| 内容安全 | 用户输入、上传内容先审 | 文件解析后分块送审 |
| 个人信息 | 隐私保护指引补"上传文件"：用途、保存期限、委托处理方（阿里云、腾讯云）；单独同意；不用于训练；数据不出境 | 律师审；和阿里云确认数据处理条款 |
| 免责 | "仅供参考"不够 | 《顾问服务说明》写明：信息工具、不代办、不保证申报结果、截止以原文和主管部门为准、延误和申报失败的损失不承担；请律师定稿 |

**第一批（名单比对、在报项目跟进表）不涉及生成式 AI**：不需要网信办登记和 AI 类目；但要更新隐私保护指引（上传客户名单）并请律师确认。

## 七、数据保存

| 数据 | 个人用户 | 机构用户 |
|---|---|---|
| 上传的申报书、营业执照等 | 分析完立即删除 | 分析完立即删除 |
| 上传的客户名单 | 7 天 | 一个申报季（180 天），可随时删除 |
| 对话记录（第二批） | 90 天 | 180 天 |
| 导出的文件 | 30 天 | 180 天；文件里嵌原文链接，删了文件依据还在 |

到期自动清理，写进隐私保护指引。

## 八、额度和收费

- **免费**：名单比对每天 1 次（≤50 家）、跟进表每天 1 次；第二批起政策解读每天 5 次。
- **机构版（付费，取得 ICP 经营许可证后，D-011）**：按客户数包月（如 50 家 / 200 家两档），名单比对和跟进表不限次数，AI 解读和条款对照有月度上限；具体价格上线前再定。
- **成本控制**：按页数、令牌、并发限额；每天、每月预算上限，超了熔断并提醒；用量和费用进运维日报。

## 十一、风险

| 风险 | 应对 |

## 十二、v1 → v2 改了什么

- **定位**：只做跨地区、多客户批量、带出处交付物（Grok：政府平台已免费做解读和匹配。长春 http://www.ccerdao.gov.cn/ztzl/rhjzc/202603/t20260305_3471781.html ；中山 http://psc.zs.gov.cn/gkmlpt/content/2/2503/post_2503040.html ；深圳 https://drc.gd.gov.cn/gzyw5618/content/post_4842422.html ）。
- **技能包重排**：新增"多客户在报项目跟进表"；"我能报哪些项目"改为"条款对照"、不下结论；"政策解读"和"材料清单"合并；新增"与去年差异"；审校暂不做（Grok）。
- **第一批不用生成式 AI**，可以先上线（Claude）。
- **合规顺序**：先登记 → 再类目 → 再提审；预留 1–2 个月；问清是否要安全评估（agy）。
- **上传**：隔离暂存、病毒检查、解析后分块送审、申报书分析完即删（agy、Codex）。
- **任务**：持久队列、状态机、幂等、重试、死信、订阅消息通知（agy、Codex）。
- **检索和联网**：段落定位、冲突优先级、代理访问、防提示注入（Codex）。
- **技能包框架**：受限配置、工具白名单、上限、签名版本、灰度回滚；测试集扩到 50 题并加红队集（Codex）。
- **导出**：渲染回归、标识自动检查、Excel 防公式注入；PPT 放第三批（Codex、agy）。
- **名单比对口径**：归一规则、未命中和同名、数据版本、逐行核对（Codex）。
- **保存期限**：机构用户文件保留一个申报季（Grok）。
- **额度和收费**：免费额度按技能包分；机构按客户数包月（Grok）。
