# AI 顾问：方案 v1（R2）

> 2026-09-29。创始人要求在小程序里加"AI 顾问"：可上传图片或文字分析，查资料库、深度思考、联网检索找答案；结果导出 PDF、Word，数据整理成 Excel，按模板做 PPT；内置可选的"技能包"。Grok（联网查官方原文）、Codex（技术架构）、agy（合规和风险）各自出方案，Claude 汇总并核对了官方原文。本方案待团队找漏洞、创始人拍板。

## 一、给谁用、解决什么

| 用户 | 典型问题 | AI 顾问给什么 |
|---|---|---|
| 企业申报专员 | "这份通知我们公司能不能报？要准备什么？" | 对照企业情况的解读、材料清单（带出处） |
| 申报咨询顾问 | "这 30 家客户，谁在今年的高企公示名单上？""给客户做一份本月政策汇报" | 名单比对报告（Excel）、月报 PPT |
| 园区企业服务人员 | "园区企业能报哪些省级项目？" | 按条件整理的项目清单（Excel、Word） |

**和现在的区别：** 现在是"查"（用户自己找、自己读）；AI 顾问是"问"和"做"（直接问问题，让它按技能包产出文件）。

## 二、功能清单

1. **对话**：文字提问，连续追问；每个回答标出引用（哪份通知、哪一段、原文链接）。
2. **上传**：图片（通知截图、营业执照、证书）、PDF、Word、Excel（如客户名单）。先做内容安全检查，再识别文字、解析表格。
3. **资料库检索**：先查我们收录的通知、名单（约 1.7 万份文件、20 万条名单，每天更新）。
4. **联网检索**：资料库找不到时才联网，**只查政府网站**（gov.cn 等白名单），引用必须给出来源链接。
5. **深度思考**：复杂问题（多个条件对照、跨文件比对）用推理模型，页面显示"正在分析"，完成后给结论和依据。
6. **技能包**：选一个技能包就是一类固定的任务，有固定的步骤、输入和输出模板（见第三节）。
7. **导出**：PDF、Word（报告、清单）、Excel（数据表）、PPT（汇报），按技能包里的模板生成；文件里带 AI 生成标识（第六节）。
8. **历史和文件**：我的对话、我的导出文件；可删除；按期限自动清理。
9. **额度**：每人每天、每月的次数和文件数上限（第八节）。

## 三、技能包（Skill）

**一个技能包 = 一份配置**，包含：名称和适用问题、需要用户提供什么（输入表单）、步骤（先查资料库 → 需要时联网 → 分析 → 校验）、能用的工具（资料库检索、名单查询、识别文字、联网）、输出格式和模板文件、校验规则（如"截止日期必须来自核对过的数据或原文"）、测试题（每个技能包 20 道，改动后必须全部通过）、版本号。新增技能包只加配置和模板，不改程序；先在测试环境跑测试题，再上线，可以随时回退到上一版。

**首批 6 个：**

| 技能包 | 用户给什么 | 产出 |
|---|---|---|
| 政策解读 | 一份通知（选我们库里的，或上传截图/PDF） | 一页纸：谁能报、支持什么、怎么报、截止时间、原文要点（Word/PDF） |
| 我能报哪些项目 | 企业基本情况（地区、行业、资质，可上传营业执照识别） | 未截止项目清单，逐条写"符合/需确认的条件"和依据（Excel + Word） |
| 申报材料清单 | 一份申报通知 | 材料清单和注意事项，逐项标出原文出处（Word/Excel） |
| 名单比对报告 | 上传客户名单（Excel，企业名称或信用代码） | 每家企业上过哪些公示/公布名单（Excel），附汇总（Word） |
| 月度政策汇报 PPT | 选地区、行业、月份，选 PPT 模板 | 本月新增申报通知、即将截止、新名单的汇报 PPT |
| 申报书初稿审校 | 上传自己写的申报书（Word/PDF）和对应通知 | 对照通知要求的缺项、格式问题清单（Word），不替用户写材料、不编造数据 |

**模板：** 每个技能包自带 1–3 套模板（PPT 母版、Word 样式），用户在导出前选；模板也是技能包的一部分，按版本管理。

## 四、页面怎么设计（小程序）

1. 底部导航或首页加"顾问"入口；进入后先看到技能包卡片（6 个）和一个通用提问框。
2. 选技能包 → 按表单填写或上传 → 提交后显示进度（识别中 → 检索中 → 分析中 → 生成文件中）。
3. 回答卡片：顶部"AI 生成，仅供参考，以原文为准"；正文；引用列表（点开跳到我们库里的文件详情，或复制原文链接）；"导出"按钮（选格式和模板）。
4. 导出完成后在"我的文件"里，点开用系统方式预览，可以转发。
5. 每次使用前第一次要单独同意《AI 顾问服务说明》（含隐私、标识、免责）。

## 五、技术架构

1. **数据流**：小程序 → 接口（鉴权、额度、限流）→ 会话服务 → 编排器（按技能包的步骤调用工具）→ 模型（通义千问：普通问题用快的，深度分析用推理模型）→ 结果和引用 → 需要导出时交给导出服务。
2. **长任务走异步**：小程序经 callContainer 调接口，单次返回不超过 1000 KiB、不能边生成边返回。所以提交后立即返回任务编号，小程序每 2–3 秒查一次进度；最长 3 分钟，超时提示稍后到"我的文件"里看。
3. **上传**：文件经小程序上传到云托管对象存储（不走 callContainer，没有 100 KiB 限制），后台取来识别；图片用通义千问的视觉模型或文字识别服务；识别后先隐去身份证号、手机号等，再分析。
4. **资料库检索**：MySQL 里已有通知、名单和核对过的字段；正文切成段落后做向量，放在托管的向量检索服务（先用阿里云百炼知识库或同类托管服务，免运维）；检索用关键词 + 向量两路，按地区、年份、类型过滤，再重排；向量服务不可用时退回 MySQL 全文检索。名单比对直接用 SQL 查，不经过模型。
5. **联网检索**：用模型服务自带的联网搜索或搜索接口，限定政府网站域名；搜到的网页只取和问题相关的段落，引用给出链接和日期。
6. **导出服务**：Word（python-docx / docxtpl）、Excel（openpyxl）、PPT（python-pptx，套模板母版）、PDF（Word 或 HTML 转 PDF）；生成后存对象存储，给有效期短的下载地址；文件元数据里写隐式标识。
7. **审计**：每次对话、调用的工具、引用、导出都记日志（沿用 D-028 的访问日志），可追溯。

## 六、合规（已核对官方原文，2026-09-29）

| 事项 | 要求 | 来源 |
|---|---|---|
| 网信办手续 | 调用已备案大模型、向境内公众提供生成式服务的，向属地网信办办理**登记**；上线后公示所用模型名称和备案号或上线编号。材料清单和办理时限没查到，要向省网信办咨询 | 网信中国公告（浙江省网信办网站转载，2026-01-12） |
| 安全评估、算法备案 | 《生成式人工智能服务管理暂行办法》第十七条：具有舆论属性或社会动员能力的，要做安全评估并办理算法备案；算法备案依《互联网信息服务算法推荐管理规定》，在算法备案系统填报，材料齐全 30 个工作日内备案。我们是否属于"具有舆论属性"，请律师和网信办确认 | gov.cn 公报 2023 年第 22 号；gov.cn 2022-01-04 |
| 小程序类目 | 一级类目"深度合成"，二级"AI问答"（生成图片另选"AI绘画"）；调用第三方技术要提交技术提供方的算法备案（生成合成类）和双方合作协议；生成内容显著位置标注"AI生成"或同等字样 | 微信小程序类目资质页 |
| 内容标识 | 《人工智能生成合成内容标识办法》（2025-09-01 施行）：文字在开头、结尾或界面显著位置提示；导出、下载的文件要含显式标识，**文件元数据要含隐式标识**（生成合成属性、服务提供者名称或编码、内容编号） | gov.cn 2025-03 |
| 内容安全 | 用户输入的文字、上传的图片和文件先过微信内容安全接口，违规的不处理 | 微信开放接口 |
| 个人信息 | 上传的营业执照、材料可能含个人信息：隐私保护指引要补"上传文件"一项（用途、保存期限、委托处理方）；单独同意；识别后隐去敏感字段；不用于训练；到期删除 | 《个人信息保护法》 |
| 免责和拒答 | 回答写明"仅供参考，以原文和主管部门解释为准"；不代写申报材料、不编造数据、不承诺申报结果；涉及造假、补报过期项目等直接拒答 | 团队规则 |

**要创始人办的：** 向省网信办咨询并办理登记；小程序加"深度合成 > AI问答"类目（需要阿里云百炼的算法备案信息和合作协议，向阿里云申请）；律师看《AI 顾问服务说明》和更新后的隐私保护指引。

## 七、数据保存

- 对话记录：保存 90 天，用户可随时删除。
- 上传的文件：分析完 7 天内删除（识别出的文字随对话保存）；营业执照等只提取需要的字段。
- 导出的文件：保存 30 天。
- 都写进隐私保护指引，到期自动清理（沿用现有的清理任务）。

## 八、成本、额度和收费

- **成本来源**：模型调用（深度思考最贵）、视觉识别、联网检索、向量检索服务、对象存储。
- **额度（免费期）**：每人每天 10 次提问、3 次深度分析、3 个导出文件；上传单个文件 ≤10 MB。额度可调。
- **省钱**：同一问题、同一文件的结果缓存；普通问题用便宜的模型；联网和深度思考设超时和预算上限；每天在运维日报里报用量和费用（沿用 D-023 的用量台账）。
- **收费**：AI 顾问适合做付费功能（机构版）。收费要先取得 ICP 经营许可证（D-011），在那之前只做免费额度。

## 十、验收标准

| 编号 | 标准 |
|---|---|
| A1 | 每个技能包的 20 道测试题全部通过：引用都能在资料库或政府网页找到原文；截止日期只来自核对过的数据或原文 |
| A2 | 名单比对报告和数据库直接查询结果 100% 一致 |
| A3 | 页面、每种导出文件都有显式"AI 生成"标识，文件元数据有隐式标识 |
| A4 | 违规文字和图片被内容安全接口拦下；身份证号、手机号在分析前被隐去 |
| A5 | 额度用完后不再调用模型；超时的任务可以到"我的文件"里找到结果 |
| A6 | 普通问题 30 秒内给出回答，文件导出 3 分钟内完成 |

## 十一、风险

| 风险 | 应对 |
|---|---|
| 登记办不下来或很慢 | 开发和手续并行；先做内部测试版；R1 不受影响 |
| AI 答错（说成符合条件） | 回答必须带引用；"我能报哪些项目"只写"符合/需确认"并列依据，不下结论；免责说明；用户可反馈纠错 |
| 成本失控 | 额度、缓存、模型分级、预算上限、日报 |
| 上传文件泄露 | 对象存储只有管理员可读、下载地址有效期短、到期删除、日志留痕 |
| 联网搜到过时或不实的信息 | 只查政府网站；给出日期和链接；和资料库冲突时以资料库核对过的为准 |
| 类目或资质不全被驳回 | 先办类目和登记，再提审 AI 顾问版本 |
