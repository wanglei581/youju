## 2. 最终方向

采用 **A 的克制排版、B 的任务顺序和操作反馈**。标识改为黑体「有据」字标，旁边可用靛蓝小字「每条都有出处」；去掉方形「据」印章。关于页和详情页注明「非政府官方平台」，每条保留官方原文链接。

宋体仅用于**文件详情页 20px 以上的文件标题**，首页及列表全部用黑体。页面底用暖灰白 `#F7F6F2`，列表面用白色。快捷入口保留一行四项：同一套 20px 线性图标、文字标签、等宽点击区，不加彩色底块和顶部粗线。

日期统一：当年列表用 `09-24`，跨年用 `2025-09-24`；截止提示写 `10月18日截止 · 剩22天`，临期才用朱红。列表按 **类型／地区／状态与截止 → 标题 → 发布机构／发布日期 → 回源入口** 排列；「公示中」与「正式公布」必须明确区分。

## 3. v2 可执行规范

| 项目 | 规范 |
|---|---|
| 色彩 | 页面 `#F7F6F2`；列表与输入面 `#FFFFFF`；正文 `#1C252B`；次级 `#59636B`；弱信息 `#79838A`；线 `#D9DED7`；主操作／链接 `#254A73`；截止警示 `#B42318`。警示色不用于品牌或普通标签。 |
| 字体 | 全局思源黑体；详情标题思源宋体。页标题 22/30、600；列表标题 16/24、600；正文 14/22、400；标签与辅助信息 12/18、500；统计数字 28/34、600。数字使用等宽数字特性。 |
| 布局 | 页面左右留 16px；间距采用 4、8、12、16、24、32px；列表行内边距 16px，行间用 1px 分隔线；输入框圆角 10px，按钮 8px，标签 4px。可点区域至少 44×44px。 |
| 列表行 | 首行放类型标签、地区、状态，截止靠右；标题最多三行；末行放机构与日期，末端给「官方原文 ↗」。无截止日期时不留空位。整行可进详情，回源链接单独可点。 |
| 标签 | 类型用浅色底加深色字；「公示中」用虚线边框，「正式公布」用实线边框并配文字。状态不只靠颜色表达。标签高度 24px。 |
| 控件 | 主按钮靛蓝底白字，次按钮白底靛蓝边，危险提示不做主按钮；按钮高 44px。搜索框高 48px，有搜索图标、清除键和明确占位文案；聚焦后显示最近搜索。 |
| 导航与空态 | 底栏四项：找答案、关注、文件、我的；图标统一 22px 线宽，选中用靛蓝，文字 11px，底栏含安全区。空状态写清是「无结果」「尚未关注」还是「该地区暂未覆盖」，各给一项下一步操作。 |
| 勾选导出 | 列表进入多选后显示勾选框和底部操作条「已选 X 条｜导出」；零条时禁用导出。点导出再选 Excel／Word，并说明包含标题、关键字段、状态、发布日期及原文链接；生成后进入「文件」。 |
