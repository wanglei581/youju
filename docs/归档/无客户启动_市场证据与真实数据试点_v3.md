# 无客户启动：市场证据与真实数据试点 v3

**整理日期：**2026-09-24  
**结论：**可以先开发，但先证明一个专题的真实来源、状态判断和文件交付链路。没有客户不妨碍技术验证；公开报告和新闻也不能替代用户付费验证。此前[总体设计与开发路线图 v2](./全行业情报与知识网络小程序_总体设计与开发路线图_v2.md)中的 G0“先取得付费意向才开发”调整为：允许启动有预算上限的无客户技术试点，商用扩张仍以真实使用和付款证据决策。

**解释：**这些证据足以说明工作量、现有替代和可用的历史样本，却没有给出“谁愿付费、愿付多少”的直接答案。不做由宽泛 AI 市场规模乘一个随意比例的收入预测。

## 2. 从全行业愿景里取一个真实技术切片

**首个专题建议：青岛专精特新中小企业名单状态。**理由是官方已有可核对的历史流程：[2025 年第二批公示名单附件](https://www.qingdao.gov.cn/zwgk/xxgk/fzj/gkml/zdly/cycx/202510/P020251009381105563711.pdf)和[正式公布文件](https://www.qingdao.gov.cn/zwgk/xxgk/fzj/gkml/gwfg/202510/t20251015_10332446.shtml)，以及 2026 年复核的公示与正式公布。2025 年第二批的正式通知列出 292 家；2026 年复核的正式通知列出 501 家。它们分别是两个批次，不能相加作“市场规模”。

**第一段真实用户流程：**指定专题及来源→检查官方栏目→记录成功/失败和时间→发现新文件与版本→区分公示/正式/复核→显示原文链接、附件和证据位置→人工确认→生成 XLSX 明细与 DOCX 简报。报告目录暂以题录导航放在“发现”，跨行业综合、自由问答、PPTX、付费席位和多平台推送放到后续验证。

**全行业仍能展示：**行业分类、地区选择与来源地图可以先开放，但每个组合必须显示“已监测、仅有来源导航、暂无覆盖”三种真实覆盖级别。小程序里不能把尚未连接的行业显示成实时周报。

**来源边界：**[国务院政策文件库](https://sousuo.www.gov.cn/zcwjk/)适合给用户跳转和手工核验；2026-09-24 读取其 [robots.txt](https://sousuo.www.gov.cn/robots.txt) 得到 `User-agent: *`、`Disallow: /`，因此不把该搜索域名列为自动采集连接器。青岛站点公开页面可用于本地小规模技术验证；生产采集、存原文、展示片段、AI 处理和再分发仍要逐动作核对站点规则与资料权利。

## 3. 无客户也能启动的六周计划

| 时间 | 要做出的可检查结果 | 没有客户时如何验证 |
|---|---|---|
| 第 1 周 | 建立官方来源与权限登记；整理 2025/2026 公示、正式、复核文件及附件的金标样本；固定试点范围 | 页面和附件能回到原站；每个状态有发布日期和人工核验人 |
| 第 2 周 | 2–3 个官方栏目连接器、检查日志、版本指纹、异常状态；每日或按站点合理频率运行 | 重复运行不产生重复版本；连接失败显示“未检查成功” |
| 第 3 周 | 名单解析、企业同名待核、状态转移、人工修订台 | 回放历史日期时，公示不得写成正式；附件行级抽样能定位原文 |
| 第 4 周 | 一个任务模板、四周基线、简报中的纳入/剔除/批注与证据抽屉 | 历史基线不被算作本周新发；错误与缺口可以追踪 |
| 第 5 周 | XLSX/DOCX 真实导出与手机查看；邮件只在有收件人授权后接入 | Office/WPS 和目标手机打开文件；出处、截至时间、状态完整 |
| 第 6 周 | 有证据约束的 AI 摘要、一次历史回放、真实运行复盘、小程序体验版 | 关键状态错误阻断交付；记录人工修订时间、漏报和来源稳定性 |

时间是假设。微信提醒规则和小程序文件操作需在当前开发者后台及真机核实；因此最初的持续提醒可以先依靠用户主动打开任务页，电子邮件和企业应用连接等取得授权后再做。开发应使用真实来源数据，但测试异常可以使用隔离的测试夹具；测试数据绝不能混入对用户展示的正式资料。

**并行市场验证：**以第 4–6 周产生的真实样本去接触 8–10 位承担此类周报任务的人，记录他们现有来源、每周工时、错误代价、愿意试用及实际支付或预付。没有客户时可以验证工程可行性与个人工作量，却不能证明商业可行；不把亲友对界面的好评记作购买意愿。

## 4. 继续、调整与停止的判据

- **继续开发：**来源按预定频率稳定可取；关键结果都能追到原站与文件版本；公示/正式/复核没有混写；对照手工流程确有可复现的工时节省。
- **调整专题：**连续几周几乎无有用变化时，增加申报节点或相邻认定事项，或改成事件通知/月报；先看信号密度，不机械坚持“每周必须有新闻”。
- **停止扩张：**如果真实来源不稳定、权利无法落实、企业名单误判难以控制，或拿样本接触目标人群后始终没有持续使用和付款信号，就保持小范围工具，不投入全行业采集与大量 AI 功能。

Claude 建议用六周样机直接回答来源与质量问题，并指出旧原型里地区与来源不匹配；Grok 强调免费政务和企查查等替代品已经强大；agy 提议用连接器、动作级权限和证据链做最小真实闭环。Codex 核查公开来源后采用“边做边验证”，并把过于绝对的验收数字及未经核实的第三方结论保留为待验证假设。

**当前完成程度：**市场与竞品案头调研、试点范围和可点击的[界面原型](./designs/industry-research/全行业情报助手_周报与来源地图_v2.html)。这不是已上线产品，也没有微信真机验收、付费用户或全部来源授权。
