# ADR 0002：礼貌抓取与合规规则

- **状态：** 已采纳（2026-09-26；同日根据 PR #10 审阅修订）
- **相关：** 总方案 v7 §6.3、§8；AGENTS.md 合规红线；决策记录 D-013

## 背景

数据来自各级政府网站的公开栏目。抓取要做到三点：
- 不给对方网站造成负担；
- 尊重网站的明确意愿；
- 出了问题能说清楚我们做了什么。

## 决定

1. **遵守 robots.txt，按 RFC 9309 处理：**
   - 读取成功：按规则判断能否抓取（我们的标识是 `YoujuBot`）。
   - 返回 4xx（包括 401、403）：视为 robots.txt 不可用，可以抓取（§2.3.1.3）。
   - 返回 5xx 或网络不通：视为全部禁止，本次跳过，下次再查（§2.3.1.4）。
   - robots.txt 自身的重定向最多跟随 5 次（§2.3.1.2）。
   - 返回的是 HTML 页面（"软 404"）：视为没有限制。
2. **重定向逐跳处理：** 不让 HTTP 库自动跟随重定向。每一跳都检查目标网站的 robots.txt，并遵守目标网站的限速；超过 5 跳即停止。
3. **透明标识：** User-Agent 保留常见浏览器标识以兼容网站，末尾写明 `YoujuBot/0.1`。
4. **网站明确拒绝时，尊重，不伪装，不绕过：**
   - **拦截爬虫标识：** 返回 403 或直接断开连接的网站，不改成普通浏览器标识去访问。
   - **防护页：** 例如返回 412 的挑战页，视为拒绝，不用浏览器渲染去"过"它。
   - 不绕过验证码、登录或其他任何防护。
   - 这类来源在来源清单中停用，改找其他官方渠道。
   - 浏览器渲染只用于没有防护、只是用脚本渲染列表内容的网站。
5. **限速：**
   - 同一网站两次请求至少间隔 3 秒，读取 robots.txt 也算一次请求。
   - 不同网站可以并行，默认最多 8 个。
6. **频率：** 每个栏目每天检查 1–4 次，只抓栏目列表页；正文按需抓取（下一迭代）。
7. **兼容老旧加密设置，但证书照常校验：**
   - 部分政府网站与 OpenSSL 3 的默认设置不兼容：旧式重协商，或不接受后量子混合密钥。
   - 默认握手失败时，对该网站改用兼容模式：允许旧式重协商，密钥交换固定用 P-256。
   - 证书校验失败一律不绕过。

## 首次全国抓取时发现的情况（2026-09-26）

| 情况 | 来源 | 处理 |
|---|---|---|
| 拦截带爬虫标识的访问 | 吉林科技厅（403）；广西科技厅、工信厅，共 3 个栏目（断开连接） | 停用；不伪装 |
| 防护页拦截脚本访问 | 甘肃科技厅、工信厅（412）；人社部（反爬虫脚本挑战） | 停用；不用浏览器渲染绕过 |

| OpenSSL 3 兼容问题 | 湖南科技厅、工信厅（BAD_ECPOINT）；江西科技厅（旧式重协商） | 兼容模式重试后正常 |

## 审阅记录

- **agy：** 建议把 robots.txt 返回 401/403 视为全站禁止。经查 RFC 9309 §2.3.1.3，4xx 一律视为"不可用"，可以抓取，所以保持现状。如果网站确实拦截我们，页面本身也会返回 403，程序会记录失败并停用该来源。
- **agy：** 指出两个问题，均已采纳：
  - 防护页不应计划用浏览器渲染处理；
  - 自动跟随重定向会绕过目标网站的 robots 检查和限速。

## 后果

- 为尊重网站意愿，覆盖面会少几个来源，这是有意的取舍。缺口在前台如实标注"暂未覆盖"。
- 所有抓取行为都能从 `source_checks` 表追溯：何时、访问了什么、结果如何。
