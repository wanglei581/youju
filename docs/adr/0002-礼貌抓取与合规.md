# ADR 0002：礼貌抓取与合规规则

- **状态：** 已采纳（2026-09-26）
- **相关：** 总方案 v7 §6.3、§8；AGENTS.md 合规红线

## 背景

数据来自各级政府网站的公开栏目。抓取要做到：不给对方网站造成负担；尊重网站的明确意愿；出了问题能说清楚我们做了什么。

## 决定

1. **遵守 robots.txt，规则按 RFC 9309 处理：**
   - 读取成功，按规则判断能否抓取（我们的标识是 `YoujuBot`）；
   - 返回 4xx（常见的是 404），视为没有限制；
   - 返回 5xx 或网络不通，视为"全部禁止"，本次跳过，下次再查；
   - 返回的是 HTML 页面（"软 404"），视为没有限制。
2. **透明标识：** User-Agent 保留常见浏览器标识以兼容网站，末尾写明 `YoujuBot/0.1`。
3. **网站明确拒绝时，尊重，不伪装。** 遇到拦截爬虫标识（403 或直接断开连接）的网站，不改成普通浏览器标识去绕过，也不绕过验证码、登录或其他防护。这类来源在来源清单中标为"网站拒绝爬虫标识访问"并停用，改找其他官方渠道。
4. **限速：** 同一网站两次请求至少间隔 3 秒（含读取 robots.txt）；不同网站可以并行，默认最多 8 个。
5. **频率：** 每个栏目每天检查 1–4 次，只抓栏目列表页；正文按需抓取（下一迭代）。
6. **兼容老旧加密设置，但证书照常校验：**
   - 部分政府网站与 OpenSSL 3 的默认设置不兼容（旧式重协商、不接受后量子混合密钥）。默认握手失败时，对该网站改用兼容模式重试一次；
   - 证书校验失败一律不绕过。

## 首次全国抓取时发现的情况（2026-09-26）

| 情况 | 来源 | 处理 |
|---|---|---|
| 拦截带爬虫标识的访问 | 吉林科技厅（403）、广西科技厅和工信厅共 3 个栏目（断开连接） | 停用；不伪装 |
| robots.txt 全站禁止 | 农业农村部 | 停用；相关政策可从中国政府网获取 |
| OpenSSL 3 兼容问题 | 湖南科技厅、工信厅（BAD_ECPOINT）；江西科技厅（旧式重协商） | 兼容模式重试后正常 |

## 后果

- 覆盖面会因为尊重网站意愿而少几个来源，这是有意的取舍。缺口在前台如实标注"暂未覆盖"。
- 所有抓取行为都能从 `source_checks` 表追溯：何时、访问了什么、结果如何。
