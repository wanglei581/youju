## 一、付费功能相关的隐私条款（不超过 600 字）

**X. 付费服务（名单比对）与财务开票**

1. **处理目的与信息种类**  
   - **订单与结算**：当您购买“名单比对按次包”时，为完成交易撮合、订单展示及售后核对，我们会处理您的微信 OpenID、系统生成的订单号、所购商品与金额、支付状态及支付时间（由微信支付平台回传）。我们不收集、不存储您的银行卡号、支付密码等敏感账户信息。  
   - **名单比对服务**：为向您提供比对分析，我们会处理您主动上传的客户名单文件（包含企业名称或统一社会信用代码），并生成比对结果文件供您查看与下载。  
   - **发票开具**：若您申请开具发票，需自行提供发票抬头、纳税人识别号及接收电子发票的电子邮箱，仅用于向您开具并交付发票。

2. **委托处理与第三方结算**  
   本小程序的支付结算通过微信小程序虚拟支付接口完成；若您在 iOS 设备（苹果手机）上进行支付，相关交易款项由苹果公司（Apple Inc.）提供结算支持。您上传的名单和生成的结果文件存储在我们委托的云服务商（腾讯云，微信云托管）处，仅用于提供本服务。

3. **数据保存期限**  
   - 您上传的客户名单，在提交 **7 天** 后由系统自动删除；  
   - 生成的比对结果文件，在服务器保存 **30 天**，逾期自动删除；  
   - 开票信息将在发票开具并妥善寄达后保存【待核实：发票留存期】；  
   - 订单交易记录在法律法规要求的期限【保存期限/待核实】内保存。当您注销账号时，我们将对该订单记录执行去关联化处理（去除与您个人账号的关联），仅用于满足财税审计与法律留存义务。

4. **您的权利**  
   您可在保存期内自行下载比对结果，或在小程序内查阅历史订单。如需撤回开票信息或行使查询、删除等权利，可通过【联系邮箱】联系【主体名称】。

## 二、AI 顾问相关的隐私条款（不超过 500 字）

**Y. AI 顾问服务（政策解读与条款对照）**

1. **处理目的与信息种类**  
   - **政策解读与要点摘录**：为向您提供政策解读与摘要，系统会将公开的政府申报通知正文传输给模型服务方处理并返回结果。  
   - **条款申报对照**：当您使用条款对照功能时，您在页面中填写的企业情况（包括成立日期、注册地、营业收入、研发费用、职工人数、已有资质），**仅保存在我们的服务器端用于比对结果的显示，不会发送给第三方大模型服务方**。

2. **第三方服务与模型训练限制**  
   我们通过微信云开发平台调用由腾讯云提供并已完成国家备案的大模型服务。【主体名称】承诺不会将您提交的业务数据用于大模型的训练或优化迭代；模型服务方在接口层面对数据的处理与留存政策详见【待核实：模型服务方的数据处理条款】。

3. **数据保存期限**  
   - 您填写的企业对照信息，在服务器保存 **7 天** 后自动删除；  
   - 系统生成的 AI 解读与比对结果，在服务器保存 **30 天**，到期自动清理。

4. **您的权利**  
   填写企业对照信息为可选操作，若不提供仅无法使用自动化比对显示功能，不影响使用基础功能。您可随时退出功能或清空本地输入，亦可通过【联系邮箱】联系【主体名称】协助清理相关分析记录。

## 三、需要律师确认的问题（最多 4 条）

1. **法定留存期限的具体时长与表述**：对于订单记录（如电子商务相关法规要求的交易信息留存期限）以及发票开具信息（财税法规要求的留存年限），此处占位符【保存期限】建议由律师明确具体的法定年份，并确认“注销账号后去关联化保存”的合规效力。
2. **企业信息与个人信息的界限厘定**：用户上传的客户名单及填写的企业信息（税号、成立日期、营收、员工人数等）多属企业法人数据，但在个体工商户或独资企业场景下可能与自然人关联，请确认在隐私指引中是否需要针对企业数据增加豁免或性质区分说明。
3. **腾讯云与大模型服务方协议审核**：需审查微信云开发/腾讯云大模型的《数据处理协议》或 API 隐私政策，核实服务方是否会利用接口输入内容进行二次训练、人工抽检或留存日志，以确保条款中“不用于模型训练”的声明准确且免责成立。
4. **iOS 虚拟支付主体的法律地位界定**：在 iOS 端通过苹果结算时，苹果公司在此流程中应被表述为“独立个人信息处理者”还是“第三方结算通道”，以及我方在隐私条款中对苹果结算端个人信息收集的免责边界是否完备。
