## 一、经营范围（设立登记时填写）

在登记系统里从《经营范围规范表述目录》勾选，不要自己写。

| 类别 | 条目 | 为什么需要 |
|---|---|---|
| 主营（放第一位） | 软件开发 | 小程序和网页是软件产品；以后申报高新技术企业、软件企业也需要 |
| 一般项目 | 互联网数据服务 | 汇总、整理、检索政府公开信息 |
| | 数据处理和存储支持服务 | 数据导出与后台处理 |
| | 人工智能应用软件开发 | AI 问答（R2） |
| | 信息技术咨询服务 | 机构年卡的对公合同和开票 |
| | 技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广 | 定制服务和技术合同 |
| | 数字内容制作服务（不含出版发行） | 政策解读、报告类内容 |
| 许可项目 | 第二类增值电信业务 | 申请 B25 许可证时，经营范围里必须有这一条 |

**设立时还没有许可证怎么写：** 许可项目可以在设立时就勾选。营业执照上会注明"依法须经批准的项目，经相关部门批准后方可开展经营活动"。拿到 B25 许可证之前，不能开通任何收费功能。

**查询入口：** agy 给出的 `jyfwyun.com` 页面标题是"经营范围规范表述查询系统"，但页面上看不到主办单位。以市场监管总局官网或当地登记系统里的入口为准。

## 三、B25 许可证（付费版上线前）

### 条件

| 项目 | 要求 | 备注 |
|---|---|---|
| 注册资本 | 在一个省内经营不少于 100 万元（跨省或全国 1,000 万元） | 按 D-012，设立时先设 10–20 万元，申请许可证前再增资。新《公司法》要求 5 年内缴足；申请时只看认缴还是要实缴证明，以属地通管局为准 |
| 股东 | 内资；股权要穿透到自然人或国资 | 一人有限公司可以申请 |
| 人员 | 一般要求 3 名主要人员在本公司缴纳社保 | 要缴满几个月以属地为准；第三方代缴无效 |
| 场所 | 与业务相符的办公场所 | 租赁合同或产权证明 |
| 网站或小程序 | 域名持有人与公司一致；网站和小程序已完成备案，能正常访问 | 小程序是否要在申请里单独填报，以属地为准 |

### 申请材料

1. 营业执照、法定代表人和经办人身份证；
2. 公司章程和股权结构图（穿透到最终股东）；
3. 3 名人员的身份证、劳动合同、社保证明；
4. 域名证书、服务器或云资源协议、备案截图；
5. 业务发展和实施计划（按 B25 信息服务写，不要套模板）；
6. 网络与信息安全保障措施（含应急预案、数据安全与用户信息保护制度）；
7. 依法经营承诺书。

### 流程和时限

在工信部[电信业务市场综合管理信息系统](https://dxzhgl.miit.gov.cn/)（本机已验证可访问）在线填报 → 属地通管局审查 → 一般 60 日内作出决定。部分省份承诺更快，以属地为准。

### 常见驳回原因

- 社保月数不够、第三方代缴、缴纳单位与申请公司不一致；
- 股权没有穿透到底，或疑似有境外架构；
- 业务计划写偏（例如写成电商或短信业务）；
- 域名持有人与公司不一致，网站打不开或内容有问题；
- **还没拿证就上线了收费功能。**

### 对 agy 草稿的更正

- 草稿说"一个自然人只能设立一家一人有限公司"。这是旧《公司法》的规定，2024 年 7 月 1 日施行的新《公司法》已经取消。
- 草稿引用的部分条文编号和工信部文件链接未能核实，这里不采用，以官方办事指南为准。

## 四、AI 问答上线前（R2）

| 事项 | 要点 | 以谁为准 |
|---|---|---|
| 网信办登记 | 只调用已备案大模型、不自己训练模型的应用，一般走属地网信办的生成式人工智能服务**登记**，不是大模型**备案** | 属地网信办 |
| 登记材料 | 安全评估报告；所调用大模型的备案信息和采购协议；违规内容过滤和应急处置机制；知识库来源说明；公司证照和安全负责人 | 属地网信办 |
| 算法备案 | agy 认为需要，以"深度合成服务提供者"身份在[算法备案系统](https://beian.cac.gov.cn/)填报，关联所调用模型的备案号 | 属地网信办 |
| 内容标识（GB 45438-2025） | ① 对话页显著提示"由人工智能生成，仅供参考"；② 每条 AI 回答带"AI 生成"标识；③ 导出的文件里带文字标识；④ 导出文件的元数据写入隐式标识。不提供隐藏标识的开关；生成记录至少保存 6 个月 | 国家标准 |

依据：《生成式人工智能服务管理暂行办法》（2023 年，七部门令第 15 号）、《互联网信息服务深度合成管理规定》（2022 年，三部门令第 12 号）、《人工智能生成合成内容标识办法》和 GB 45438-2025（2025 年 9 月 1 日施行）。

## 五、打电话时要问的问题

1. 一人有限公司申请 B25，主要人员社保要几个人、交满几个月？

3. 只有微信小程序、没有网站，可以申请吗？小程序要不要在申请里单独填？

1. 小程序调用已备案的大模型做问答，走"登记"还是"备案"？要什么材料、多久？
2. 还需要单独做算法备案吗？以什么身份？
