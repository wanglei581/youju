## 一、为什么要改、改了什么

2.0 把后台从"微信云托管"搬到自己的服务器上，用户能感到的功能不变，但下面几件事变了，现行指引写的和实际做的会对不上，所以要改版：

| 现行（2026-12）写的 | 2.0 实际怎么做 |
|---|---|
| 小程序"通过微信云托管调用我们的服务，微信会在每次请求中自动附带 openid" | 小程序打开时调用微信登录（wx.login）拿一次性登录码，服务器拿它向微信换 openid，再发一个**加密的登录凭证**存在手机上，之后每次请求带上它 |
| 访问日志里的来源 IP 是"微信云托管转发请求时附带的" | 由我们服务器前面的反向代理记下连接的来源 IP |
| 存储在"腾讯云服务器（微信云托管的云数据库和对象存储）" | 存储在腾讯云**轻量应用服务器**上的数据库和硬盘；每天的备份另外**加密**后存一份在腾讯云**对象存储（COS）**，密文再存一份在我们公司的电脑上（创始人 11/5 定） |
| 数据"经微信云托管的通道加密传输" | 经 HTTPS 加密传输；管理后台不对公网开放 |
| 腾讯云：服务器（微信云托管）和数据库托管 | 腾讯云：云服务器（轻量应用服务器）、对象存储（只放加密的备份） |

**不变的：**收集的个人信息种类、用途、保存期限都不变（备份仍保留 30 天，异地那份也是 30 天）；同意本指引之前仍不保存 openid；境外传输仍只有苹果退款问询那一项；委托处理方仍是腾讯云（主体还是腾讯云计算（北京）有限责任公司，购买服务器时核对合同主体）和深度求索。

**本机不放个人信息的明文：**2.0 的抓取和处理在创始人自己的电脑上做，那台电脑上有政府公开发布的通知、附件和整理结果；用户数据的明文从来不传过去（同步是单向的：电脑 → 服务器，只传公开内容）。唯一的例外是创始人 11/5 定的"整库备份在本机再留一份"：留的是**加密后的密文**，那台电脑上没有解密的私钥（私钥由创始人另外保管），所以指引的存储地点里要写上它（见下面第 5、6 段）。**这一条要创始人确认**：写进指引、照这样做；或者不在本机留备份副本，指引里就不写。内部规则：下架时的备注不写投诉人的姓名和联系方式（同步时备注也会清空，见 `youju/sync/tables.py`）。

## 二、版本号和重新同意

- 新版本号建议用**切换那个月**，例如 `2027-01`（现行 2026-12；版本号按时间比字符串，必须比 2026-12 大）。
- 建议**要求重新同意**：取得 openid 的方式（处理方式）变了，按《个人信息保护法》第十四条第二款，处理方式变更要重新取得同意。做法和以前升版一样：
  - 服务器 `YOUJU_AGREEMENT_VERSION` 和 `YOUJU_AGREEMENT_MIN_VERSION` 都设成新版本号；
  - 用户打开 2.0 小程序后，凡是要登录的功能都先弹出新版协议、同意后才能用（关注、纠错、批量工具、AI、购买），只看通知、检索、导出不受影响；
  - 只同意过旧版的老用户：数据都在（切换时整库搬过来），重新点一次同意就行。
- 另一种做法（不推荐）：`YOUJU_AGREEMENT_MIN_VERSION` 留在旧版，只更新文本、不强制重新同意。省一步，但处理方式变了却没有重新取得同意，合规上站不住。

### 2. 一·2 微信用户标识（openid）的"方式"

**现行：**· 方式：本小程序通过微信云托管调用我们的服务，微信会在每次请求中自动附带 openid，不需要您另外授权。在您同意本指引之前，我们不建立账号记录，只在处理请求时用它：……

**草稿：**· 方式：您打开本小程序时，本小程序调用微信登录接口取得一个一次性的登录码，发给我们的服务器；服务器拿它向微信换取您的 openid，再发给您一个**登录凭证**。登录凭证是加密的，里面只有 openid 和到期时间（7 天），保存在您手机的本地缓存里，之后每次请求都带上它，过期后自动重新登录，不需要您另外授权或操作；我们的服务器不保存登录凭证，也不保存微信给的会话密钥。在您同意本指引之前，我们不建立账号记录，只在处理请求时用 openid：判断您是否已同意；判断您是否在测试名单里（新功能对所有人开放前，先给少数测试账号试用；名单由我们在服务器上手动设置，不会自动加入）；在服务器内存里统计 10 分钟内导出和打开附件的次数，防止滥用（您同意之后也这样统计）；算出访问日志里的去标识化编号（见第 8 项）。这时 openid 本身不写入数据库：计次用的记录留在服务器内存里，到服务重启或因记录太多被清掉为止；访问日志暂时写不进数据库时，待补写的记录连同 openid 先留在内存里，补写成功或服务重启后清除；访问日志写进数据库的只有算出的编号。

（只改了第一句和第二句；"在您同意本指引之前……"以下和现行一字不差。）
