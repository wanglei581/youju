## 这张样张暴露的产品需求

1. 一条资料卡必须同时显示**官方发布日期、首次观测时间、检查时间、文件版本和发布阶段**；没有连接器时不伪造观测/检查时间。
2. “公示→正式”要作为**状态链**展示，企业行证据晚于通知标题级证据核验。
3. 申报事项须按“适用主体×动作×渠道×截止日”拆节点，并支持后续更正。
4. 每份导出报告保留覆盖缺口与截至时间；原站后续更正时标记受影响的旧报告，而不改写用户已下载文件。

**样张通过条件：**下一版从许可范围内核对至少两份附件的末行序号及抽样企业名称，补齐栏目覆盖与原页访问记录；再由资料负责人签核后，才能转为对外示范内容。
