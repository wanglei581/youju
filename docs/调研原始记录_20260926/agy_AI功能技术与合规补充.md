# 架构、AI方案与合规落地报告（agy-C）

> **角色定位**：agy（架构 / 合规 / 数据源）  
> **核心结论先行**：
> 1. **分阶段切入**：首发版本**先不上生成式AI界面**，以“工具-信息查询”纯检索/日历快速上线（避开网信办前置等待），并行办理大模型合作协议备案与省内ICP证，通过版本升级平滑解锁深度AI功能。
> 2. **合规路径优化**：一人有限公司注册资本建议**“先设20万，办ICP前增资至100万”**，规避新《公司法》高额实缴风险；全国性小程序只需**省内B25许可证**，无需跨地区1000万资质。
> 3. **一人极简架构**：微信小程序云开发负责高频低延迟交互，阿里云百炼/腾讯云负责长文本解析与夜间批处理；90%数据运营交由AI质检闭环，创始人每周人工抽检仅需**2.5~3.5小时**。

### 1.1 AI 功能分期规划与技术清单（P0 ~ P3）

| 优先级 / 功能名称 | 用户核心价值 | 关键实现技术 | 所需数据 | 单次预估成本 | 主要风险与防错措施 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **P0 对话式搜索** | 自然语言查找政策与申报项目（如“上海张江集成电路补贴”） | 混合检索（向量Embedding + BM25全文）+ 重排序（Cross-Encoder Rerank）+ 轻量模型意图识别 | 结构化政策库、向量索引 | 0.003 ~ 0.008 元 | **检索漂移**：设置相似度阈值（<0.75触发降级提示）；强制限定检索库范围。 |
| **P0 政策速读卡** | 10秒看懂扶持核心（对象、补贴上限、截止日、申报要点） | 结构化JSON抽取 + 双模型交叉校验（轻量模型抽取+重模型验证关键数字） | 官方通知正文、政策解读文 | 0.01 ~ 0.03 元 | **关键数据幻觉**：资金/时间必须由正则/规则回查原文，不一致强制标红降级。 |

| **P0 AI 质检员（后台）** | 保障抓取数据的高可用、无乱码、时效性 | 规则引擎（死链/乱码）+ 文本完整性与分类打分Agent | 爬虫入库暂存数据、历史基准 | 0.005 ~ 0.01 元/篇 | **漏检伪正文**：对正文字数<200字或相似度异常的文件自动截流，进入人工抽检池。 |
| **P0 来源接入 Agent** | 输入任意政务URL，自动生成网页抓取与解析规则 | Agent工作流（DOM树解析 + CSS/XPath生成 + 模拟抓取验证） | 目标网页HTML源码 | 0.05 ~ 0.10 元/站点 | **反爬与动态加载**：集成无头浏览器（Playwright）渲染，规则生成后跑回归测试集校验。 |
| **P1 客户名单批量匹配** | 服务机构上传客户名单（Excel），批量比对申报资质与名单公示 | 批量企业图谱匹配 + 向量批量召回 + 并行化规则打分 | 用户上传Excel、全量公示名单库、企业工商标签 | 0.5 ~ 2.0 元/批 (百家) | **同名与简称混淆**：统一社会信用代码优先，无代码时采用模糊字面率+地域双重校验。 |
| **P1 周报/简报生成** | 一键生成带出处、带原文超链的行业/政策周报底稿 | 动态多源RAG + 长上下文信息合成 + Markdown/Docx渲染引擎 | 本周新政、行业运行指标、研报摘要 | 0.15 ~ 0.40 元/份 | **出处悬空**：强制要求引用标记带源数据库Doc_ID，未召回原文一律不生成论据。 |
| **P1 政策版本比对与解读** | 国家与地方落地细则对比、新旧修订版逐条差异解读 | 文本Diff对齐算法 + 条款粒度语义比对 + 影响差异化解读Prompt | 新旧政策文本、国家/地方配套文件 | 0.08 ~ 0.20 元/次 | **对比错位**：先按章/条/款层级做结构化树状对齐，再行比对，避免大段位移错乱。 |
| **P2 PPT 大纲与内容生成** | 周报或深度解读一键转为汇报用幻灯片 | 内容层级分块（Outline Generation）+ 模板填充（python-pptx/前端JSON组件） | 政策速读结果、周报结构化数据 | 0.10 ~ 0.30 元/份 | **文字堆砌**：强约束每页字数（<80字），采用提纲化、要点式输出，提供多套版式。 |
| **P2 库外“AI 找资料” Agent** | 库内无结果时，动态联网调度指定政务门户爬取入库 | 搜索规划器（ReAct Agent）+ 官方白名单域名检索 + 自动化解析入库 | 目标部委/厅局站点结构、实时网络请求 | 0.20 ~ 0.50 元/次 | **防爬超载与死循环**：单任务设置Max Iteration=4；仅限检索白名单域名（.gov.cn等）。 |
| **P2 跨行业对比矩阵** | 纵览不同战略新兴产业的政策扶持力度与准入门槛 | 多维矩阵生成Agent + 指标归一化（奖补梯度/门槛等级） | 多行业政策标签数据 | 0.05 ~ 0.15 元/次 | **指标维度不可比**：设定统一对比范式（资金/税收/人才/用地），不支持的留空。 |
| **P3 申报窗口预测** | 根据历年规律，提前预测申报启动时间并生成备战建议 | 历史时序统计算法 + 规律推理模型（往年发布月份、节假日修正） | 历年通知发布时间戳、立项公示时间 | 0.01 ~ 0.03 元/条 | **政策突变**：明确标明“置信区间（如：通常在4月中旬，准确率85%）”，不作绝对承诺。 |

### 1.2 云平台与已备案大模型选型（2026年）

```
[前端/小程序] ──> wx.cloud.extend.AI (腾讯混元 / DeepSeek-V3) ──> 高频轻量交互 (对话搜索、速读卡)
      │
      └───[后端批处理网关] ──> 阿里云百炼 (Qwen-Long / Qwen-Max / DeepSeek) ──> 重度任务 (周报长文、版本比对、Agent)
```

1. **微信云开发（`wx.cloud.extend.AI`）**：
   - **支持模型**：腾讯混元（Hunyuan）、DeepSeek系列、GLM、Kimi等。
   - **适用任务**：小程序前端直接调用、流式对话问答、政策轻量级速读。
   - **核心优势**：免运维、小程序原生授权免鉴权、2026年微信官方提供免费算力额度扶持计划。
2. **阿里云百炼（Bailian）**：
   - **支持模型**：通义千问系列（Qwen-Max/Plus/Long/Turbo）、DeepSeek全系列。
   - **适用任务**：超长政策与附件解析（Qwen-Long支持百万级Token上下文）、企业周报生成、后台复杂Agent工作流。
   - **核心优势**：文档解析API（Doc Parser）生态成熟，结构化抽取质量极高。
3. **腾讯云知识引擎/混元生态**：
   - **适用任务**：RAG知识库检索、政务合规词过滤、与微信生态对象存储（COS）联动。

### 1.3 一人团队评测体系与成本控制

#### 评测体系（Eval）
- **金标测试集（Golden Set）**：人工构建 **100篇典型政策文件 + 300条问答事实对**（涵盖申报时间、金额上限、硬性指标、附件要点）。
- **自动化回归门槛**：每次Prompt或模型版本迭代，CI脚本自动执行评测。
  - **关键要素抽取准确率 ≥ 99%**（时间、金额绝不允许幻觉）。
  - **引用原文命中率 = 100%**（未在正文中出现的句子不得打上引用标）。
  - **合规词安全通过率 = 100%**。

#### 成本控制策略
1. **语义缓存（Semantic Cache + Redis）**：对高频搜索与速读卡进行缓存，相同/高相似度问题直接返回已有抽取结果，预计降低 **60%** API 调用开销。
2. **离峰批处理（Batch API）**：周报汇总、行业矩阵、后台爬虫解析全部安排在夜间（02:00~06:00）运行，享受云厂商批处理专属阶梯折扣（约5折）。
3. **额度熔断机制**：免费用户每日限次，Agent递归调用强制限定最大步数（Max Steps ≤ 4），防止极端Prompt引发Token雪崩。

### 1.4 数据运营自动化分工与工时预估

*在“1人 + AI”架构下，全链路运营分工如下：*

- **完全由 AI 自动化处理（占 92% 工作量）**：
  1. 300+ 重点政务站点每日定时巡检与抓取；
  2. 正文去噪、附件下载与OCR文字识别；
  3. 政策标签化（地域、行业、级别、申报类别）；
  4. 政策速读卡生成与入库前结构化打标；
  5. 自动检测失效链接与正文截断异常。
- **必须人工抽检/处理（占 8% 工作量）**：
  1. AI质检员标记评分低于 90 分的文件复核（通常为表格扫描件）；
  2. 补贴金额超 500 万或国家级重大人事/项目名单抽检；
  3. 新增冷门数据源的规则接入终审。
- **每周创始人人工投入**：**约 2.5 ~ 3.5 小时/周**（平均每天早晨花 20~30 分钟通过后台管理面板处理异常预警即可）。

## 任务 2：合规补充（逐项联网核实）

### 2.1 一人有限公司申请 ICP 经营许可证（B25）
- **注册资本与覆盖范围**：
  - 法规标准：省内业务最低注册资本为 **100万元**，跨地区（全国）业务为 **1000万元**（认缴即可）。
  - **实操裁定**：微信小程序作为纯线上SaaS与数据查询工具，无跨省实体分支机构，**仅需向公司注册地省通信管理局申请“省内B25（信息服务业务-仅限互联网信息服务）”即可面向全国微信用户提供服务**，微信平台资质审核完全认可省内ICP证。无需申请工信部跨地区1000万许可证。
- **社保与人员要求**：通常要求企业提供至少 **3名员工** 近期（1~3个月）连续缴纳社保证明；人员需具备计算机或相关专业大专以上学历。一人公司可通过合规聘用技术/运营顾问代缴合规解决。
- **材料与周期**：
  - 核心材料：营业执照（经营范围含“增值电信业务”）、公司章程、法人身份证、3人社保证明、域名注册证书（必须在境内且已完成ICP备案）、网络与信息安全保障措施及应急预案。
  - 审批周期：通信管理局自受理之日起法定期限60日内，实际经专业代办预审后通常在 **20 ~ 40 个工作日** 出证。

### 2.2 新《公司法》（2024年施行）“认缴5年内缴足”对 100 万注册资本的影响与策略
- **法律影响**：新设立公司自成立之日起 **5年内** 必须足额完成 100 万元实缴并向公信系统公示；若公司出现未清偿债务或破产，未届期的认缴出资面临“加速到期”全额追偿。
- **一人有限公司特殊风险**：新《公司法》第23条保留了**财产混同举证责任倒置**——若一人股东不能证明公司财产独立于股东个人财产，需对公司债务承担**无限连带责任**；且依据第208条，每年会计年度终了必须强制聘请会计师事务所出具**财务审计报告**。
- **实操应对方案**：
  1. **“先低设，后增资”**：初创设立时注册资本设为 **10万 ~ 20万元**，减轻初期5年实缴资金占用与责任敞口；
  2. **办证前夕定向增资**：待产品MVP验证通过、启动申办ICP经营许可证前夕，通过股东决议增资至 **100万元**；
  3. **严格财务隔离**：杜绝个人微信/支付宝收取公司公款，规范做账并按年度出具正规审计报告。

### 2.3 微信小程序“连续包月/自动续费”开通条件与法律合规
- **微信端规则（2026年最新）**：
  - 虚拟商品（会员订阅、AI算力）已在全终端（iOS/安卓/鸿蒙）**强制要求接入微信官方“虚拟支付”系统**，严禁跳出或使用普通支付。
  - 虚拟支付原生支持“订阅型商品”（按周/月/季/年自动续期），开通条件为：企业主体、已开通虚拟支付商户号、微信认证有效、近期用户投诉率低于 0.05%。
- **国内法律硬性要求**：
  - 依据《网络交易监督管理办法》（总局令第37号）第18条及2024年7月1日实行的《消费者权益保护法实施条例》第24条：
    1. **事前明示**：购买前前端必须以显著文字说明自动续订规则与价格，**严禁默认勾选**；
    2. **扣费前5日主动提醒**：在自动续费扣款前 **5日**，必须以显著方式（微信服务通知或短信）提醒消费者扣款时间与金额；
    3. **一键取消**：小程序内必须提供显著、简便的随时退订入口，不得设置恶意流程阻碍退订。

### 2.4 主类目、深度合成类目与虚拟支付共存可行性
- **结论**：**完全可以同时并存，不冲突**。
- **配置架构**：微信小程序支持最多添加 5 个服务类目。推荐主类目选“**工具—信息查询**”或“**企业服务—软件/办公**”，增选“**深度合成—AI问答**”。
- **虚拟支付互通**：“工具”类目处于微信虚拟支付的资质准入白名单中，开通虚拟支付后即可合规售卖会员订阅与AI查询额度。

### 2.5 分阶段上线可行性（网信办登记前先上不含生成式AI版本）
- **结论**：**完全可行，强烈推荐作为首发策略！**
- **实施节奏**：
  - **第一阶段（极速首发）**：小程序仅申请普通“工具—信息查询”类目，仅开放政策通知浏览、多维筛选、关键词搜索、申报日历与Excel名单匹配导出。**完全不涉及LLM对话生成，免办“深度合成”类目与网信办生成式AI登记**，仅凭常规小程序ICP备案，**1 ~ 2 周内即可过审上线**，抢占种子用户。
  - **第二阶段（资质升级）**：同步与云厂商签署大模型采购合作协议（含算法备案号），在属地网信办完成生成式AI应用上线登记；完成后在小程序后台添加“深度合成—AI问答”类目，代码版本升级放开AI速读卡、对话搜索与周报生成。
