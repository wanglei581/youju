查找中的主要问题：

1. 多数省不设单一“通知公告”。江苏工信、浙江经信拆成“文件通知”和“公告公示”；山东工信拆成“通知”和“公示”；上海科委用“办事通知告示”；辽宁、吉林、浙江科技厅用“通知通告”。
2. 天津工信的通知公告父页会跳进当年子目录（现为 `2026n`），跨年采集要跟着换目录。上海科委路径 `tzgs/zhtz`（综合通知）打开是模板报错，在用列表是“办事通知告示”。
3. 江苏科技厅官网域名是 `kxjst.jiangsu.gov.cn`。安徽工信部门现称工业和信息化厅，站点仍挂在原经信域名 `jx.ah.gov.cn`。山西工信能翻页的列表在 `index_7002.shtml`，目录页本身不出条目。
4. 浙江科技厅、江苏工信厅、江西工信厅的列表正文由脚本加载，静态页面看不到标题；栏目页和 2025–2026 年文章路径已核对。山东两厅的 https 证书主机名不匹配，列表以 http 打开。黑龙江科技厅主栏叫“公示公告”，计划类通知在另一栏“科技计划通知”。
