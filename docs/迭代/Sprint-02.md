# Sprint 2 · 原型确认与数据底座常态运行

- **时间：** 2026-09-26 起（原计划第 3–4 周，10/12–10/25；Sprint 1 提前完成）
- **GitHub：** 里程碑 "Sprint 2 · 原型确认与数据底座常态运行"，Issue #11–#19
- **目标：**
  1. 做出小程序免费版（R1）的可点击原型，创始人确认后再开发前端；
  2. 数据底座每天自动运行、出问题有人知道，并补上已找到接口的来源。

## 为什么先做原型

后端数据底座不依赖界面，所以先做了（Sprint 1）。小程序界面要先由创始人确认：确认后再开发，避免返工。原型还决定后端要提供哪些字段（截止日期、地区和行业标签、名单状态等），据此排后面的数据任务。

流程：信息架构 → 可点击原型 → Grok 竞品界面对比、agy 合规审阅 → **创始人确认** → 视觉规范 → 开发。

**进展（2026-09-27）：** 原型 v1 已完成；四种风格对比后，团队一致推荐"A 的排版质感 + B 的信息结构和操作"（见[风格选择记录](../设计/风格选择_2026-09-27.md)），等创始人确认后按 v2 规范重做 9 个页面。
