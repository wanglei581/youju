### 电脑版微信要多看的 6 步

电脑版（Windows、Mac 的微信里打开小程序）此前没人测过。Codex 10/11 先从代码里排查了一遍，Claude 在本机取微信官方接口文档核对了支持情况：

| 接口 | 用在哪 | 官方文档写的电脑版支持（2026-10-11 取回） |
|---|---|---|
| `wx.openDocument` | 打开附件、打开导出的 Excel/Word | Windows 版支持、Mac 版支持 |
| `wx.getFileSystemManager` | 保存导出文件和附件 | Windows 版支持、Mac 版支持 |
| `wx.setClipboardData` | 复制原文链接、复制邮箱 | Windows 版支持、Mac 版支持 |
| `wx.showActionSheet` | 导出时选 Excel 还是 Word | Windows 版支持、Mac 版支持 |
| `wx.openPrivacyContract` | 关于页打开隐私保护指引 | Windows 版支持、Mac 版支持 |
| `wx.getWindowInfo`、`wx.getMenuButtonBoundingClientRect` | 首页、查名单的蓝色顶部 | Windows 版支持、Mac 版支持 |
| `wx.shareFileMessage` | "文件"页的"转发" | **文档没有列 Windows、Mac 版**，很可能不支持；代码里取不到这个接口时会提示"请点'打开'，再用右上角菜单转发" |

顶部导航栏的高度原来按"状态栏至少 20"算，电脑版状态栏是 0，可能把顶部挤成一条；10/12 已改成按实际值算，取不到或数不合理的那一项才用默认值（`apps/miniapp/utils/nav.js`；手机上的结果和原来一样），仍要实测确认。
