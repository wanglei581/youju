## 用户流程逐项验收

使用合成企业；不得向外部模型提供密钥、生产库或客户信息。真实政府正文调用只走项目已授权且脱敏的既有后端流程。

1. 基础查询：首页 → 地区/类型筛选 → 通知详情 → 官方原文/附件 → 截止说明 → Excel/Word → 文件记录 → 再次打开。覆盖未核对日期、下架、附件过期和网络失败。
2. 本机客户：添加两家合成企业 → 修改地区 → 合并相关通知 → 删除一家 → 导出 → 重启恢复。打开工具中心不自动上传卡片；批量表单另行填写并告知上传。
3. 免费比对：支付关闭、AI 关闭 → 工具中心 → 比对 → 未同意时不预览/上传 → 阅读并勾选工具说明 → 粘贴两家 → 预览行数 → 提交 → 排队/处理/完成 → 下载 Excel → 文件记录重新下载。重复点击与超时重试不得重复建任务。
4. 客户通知表：CSV/XLSX 选择 → 大小/扩展名/内容错误提示 → 服务器预览 → 50 行内成功 → 51 行拒绝；已有使用期按服务器 500 行权益处理，无购买前置。文件仅本次内存暂存，成功或卸载清除。
5. 任务边界：取消 queued 退回占用额度；running 不可取消/删除；失败后可重新填写；完成无结果、30 天过期、文档下架、403/404/410 均正确反馈。不完整下载不写文件记录。离开页面停止下一段与轮询，返回重新读取权限。
6. AI 解读：合格通知 → 显式标识和须知 → 六类摘录（含材料）→ 每项回原文核对 → 隐藏/恢复 → 失败重试 → 投诉通过反馈渠道受理。AI 关闭不能影响第 3、4 项。
7. 条款对照：填写结构化企业情况 → 校验 → 幂等任务 → 对照原文引用 → 恢复 → 删除。验证不显示“符合/不符合”结论、输入不发模型。
8. 提醒：本人主动授权一次 → 服务端记录 → 到期 cron → 手机真实收到 → 点击对应通知 → 重复运行不重复发送 → 撤回或删除关注后停止。未配模板不得承诺收到提醒。
9. 我的数据/注销：复制本人记录；数据工具仅导出任务元数据，不宣称包含名单输入全文。任务中心删除任务与服务器结果；注销删除关联个人信息并清理本机文件。已转发副本需用户自行管理。
