## 1. 哪些已经被免费满足，哪些没人做好

已经有免费或近免费产品接住的功能：

| 功能点 | 谁已经免费或近免费做了 |
| --- | --- |
| 按关键词查国家政策原文 | 国务院政策文件库 |
| 查本地惠企政策、看申报还剩几天、订阅新政策 | 工信部政策找企、黑龙江、广州、南昌、银川 |
| 企业符合条件就匹配奖补，部分直接兑现 | 各地惠企平台、免申即享 |
| 查一家公司有没有高企、专精特新等标签，并关注这家公司 | 企查查 / 天眼查免费层加年费几百元的会员 |
| 找券商和咨询机构 PDF，在线读、限量下 | 发现报告、萝卜投研普通版、三个皮匠免费预览 |
| 用自然语言搜公开资料，并生成 Word、PPT、表格草稿 | 豆包免费额度、Kimi 免费额度、DeepSeek |

市场上没有看到稳定产品接住的功能，具体是这几件：

1. 研究员视角的监测，不是企业主视角。政府平台问的是「这家公司能报什么」。没有公开产品按《国民经济行业分类》加地区加来源，每周只在官方栏目真正更新时出一份周报。青岛那个「52 周只有 25 周有新公告」的初核，说明按周硬出报会注水，而现有「政策通」不会替用户判断「这周没有新公示」。
2. 认定名单的状态，而不是一堆 PDF。公示稿、正式公告、申报截止，三套文件要能对上同一批企业，并导出成表。政府站有原文，企查查有结果标签，两边都不做「这篇公示和三个月后的正式名单差了谁」。
3. 每个格子都能点回原文。文号、发布日期、栏目 URL 要跟在数字旁边；对不上就写「无法确认」。通用 AI 能带链接，但不能把这个规则做成产品默认值。研报库给的是别人写好的 PDF。
4. 一次交付里同时有政策、统计、名单、协会或大厂白皮书，并标明来源等级（政府原文 / 协会 / 企业白皮书）。三个皮匠的政策库最接近，但只是限额下载，不生成这份整合底稿。
5. 来源地图本身。腾讯云产业干货、大厂白皮书、协会报告分散在各站。聚合站在做「报告发现」，但没有按来源可信度分层，也不能合法地变成全文库。这是发现服务，不是全文搬运。

## 3. 一句话定位

做产业研究、政府事务和招商岗的官方出处工作底稿：按行业和地区，把公示、正式名单、统计和申报截止收成可导出、可点回原文的表，有更新才出周报。

这条定位能躲开三面夹击。免费政策平台负责「企业去领钱」，免费 AI 负责「写一篇像报告的东西」，研报库负责「别人已经写好的 PDF」。三者都不对名单状态和原文格子负责。用户付钱，是为了少返工，以及汇报时每个数字都能打开政府原文。全行业可以做导航，深度只做少数地区的认定名单和截止节点。青岛已有的初核说明，周报必须允许「本周无新公告」，否则产品和事实相反。
