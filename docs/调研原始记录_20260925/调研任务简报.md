# 项目背景简报（供联网调研使用）

今天是 2026-09-25。你是一个产品/商业调研顾问团队成员。**只做联网检索与分析，不要创建、修改或删除任何文件。**

## 项目是什么
一个个人创业者（目前没有客户、没有团队规模信息、尚未注册小程序）想做一个**微信小程序**，暂名「行业政策」：
- 面向**职场人**（企业政策/政府事务岗、产业研究/战略岗、咨询顾问、科技服务/企服机构、园区招商、投资研究等），他们每周都要去国家和地方政府网站、行业协会、研究机构网站搜集：行业政策、行业统计数据、行业研究报告、企业获奖/认定名单（如专精特新、高新技术企业、瞪羚、单项冠军等）。
- 小程序内置 AI 助手：用户说出需求 → 直接得到**有官方出处**的结果（政策、数据、名单、报告），可以 AI 追问，可以**导出成 Excel / Word / PDF / PPT**，可以做**跨行业整合报告**。
- 可以**每周自动监测**用户关注的行业/地区/来源，形成周报。
- 想把"别人不知道的"企业资料库（如腾讯云产业互联网干货库、各大厂白皮书、协会报告）聚合起来做**报告发现/来源地图**，让"信息不再是孤岛"。
- 覆盖**全行业**（按《国民经济行业分类》分类选择），但深度内容逐步建设。
- 参考对象：朋友做的医疗医保医药数据小程序「数看三医」（有法规搜索、分类筛选、会员入口）。

## 前期讨论（在另一个 AI 工具里）已形成的方向
- 核心原则："后台整理资料，前台交付结果，每个结果可追溯原始出处"；证据不足时明确说"无法确认"。
- 小程序四个入口：找答案 / 关注 / 文件 / 我的。
- 首个深做专题候选：青岛企业认定名单（公示→正式公布）与申报截止节点。初核发现两个青岛官方栏目 52 周里只有 25 周有新公告，每周都有新内容不成立。
- 初步收费假设（未验证）：免费（题录+原站链接）；按次 ¥29–79/份；个人专业版 ¥99–199/月；团队版 ¥799–1999/月；企业版定制。
- 已知替代品：各地政府"政策通"类平台（免费政策匹配与订阅）、企查查等企业信息平台（含导出与关注企业周报）。
- 当前只有：HTML 可点击原型、微信原生小程序骨架、本地 Python 后台（CSV/XLSX 导入→审核→发布→XLSX/DOCX 导出），无真实数据、无 AppID、未上线。

## 调研要求（所有任务通用）
1. 必须联网检索，优先 2025–2026 年的信息；每个关键事实附**来源链接**和**发布日期**。
2. 查不到就写"未查到"，不要编造数字、价格、公司名或链接。区分"官方/一手来源"和"媒体/自媒体转述"。
3. 用中文输出，结构化（表格优先），结论先行。
4. 结尾附：`不确定/待核实事项` 列表。
