# 区县部门：误配修复和信息公开平台的部门目录规则（2026-11-09）

区县接入（D-126：11/28 起按省分批，12/10 前后收齐）之前要先做的两件公共的事：

1. **误配修复**：区县门户上链到市直、省直、外省部门的链接，不再当成区县自己的部门；门户认错的否掉。
2. **部门目录规则**：县直部门多半没有独立网站，列在门户"政务公开→部门信息公开"一类的页面里。盘点现在会去找这类目录页，按平台读出每个县有哪些部门、各自的栏目。

代码在 `backend/src/youju/govsites/`：`attribution.py`（归属判断）、`deptdir.py`（部门目录）、`deptdir_trial.py`（按县试读），接在 `inventory.py` 找部门的几个函数里，`youju coverage-inventory` 默认对区县级找部门目录。只读公开页面，抓取沿用盘点的页面缓存（遵守 robots.txt、同一网站两次请求至少隔 3 秒、透明标识），登录、验证码、412/521 防护照记"不能抓"，不绕过。

## 一、误配修复

### 查出来的问题（11/8 全国清单）

| 类型 | 规模 | 例子 |
|---|---|---|
| 区县部门挂到市直、省直部门网站 | 约 950 格（内蒙古 206、四川 131、重庆 124、江西 85、宁夏 81、辽宁 76……） | 康定市"财政厅"→四川省财政厅；呼和浩特新城区"发展和改革委员会"→呼和浩特市发改委；九江濂溪区"科技局"→九江市科技局；应城市"湖北商务厅"→湖北省商务厅 |

### 规则（`attribution.py`）

判断一个部门链接、部门网站是谁的，按下面的顺序，**判不出的照常认**（不猜，留给人工核对）。

1. **链接文字**（找候选时）：
   - 本地写法：市、县级**不带省简称**（应城市的"湖北商务厅"不再加分）；
   - 以上级地名开头的去掉地名再看："四川省康定市财政局"是康定市的，"四川省财政厅""呼和浩特市发展和改革委员会"是上级的；
   - 以本省别处地名开头的是别处的，以外省地名开头的是外省的（青海海南州、河南县这类和外省同名的，本地写法更长才算本地；和外省同名的简称后面跟"厅"的，如天津河北区页面上的"河北工业和信息化厅"，算外省）；
   - 开头的层级字："省科技厅""自治区发改委"在市县门户上是上级的，"区科技局"在区里是本级的；
   - 市县门户上以"厅"结尾的（"财政厅""吉林科技厅"）是省级部门：市县没有厅；
   - 派出分局（"杭州市生态环境局西湖分局""市生态环境局黎城分局""西夏区生态环境分局"）算本区县的，先于层级字判断；本地名称后面要紧跟"分局""区分局"这类结尾，"岳阳楼分局"不算岳阳县的。
2. **部门网站本身**（抓到页面后）：
   - 本地门户里的部门频道放行（集安市门户全站的网站名写着"通化市人民政府"、广东集约化门户首页带省里的标识码，按它们判会把本地部门全排掉）；
   - 网站自己写的网站名（meta SiteName，没有就看标题各段）按上面的名称规则判断；
   - 网站标识码（10 位，前 6 位是行政区划代码）→ 本地、上级、别处、外省（不是 10 位、或代码不在区划库里的不用）；
   - 网站在上级门户的域名下、不在本地门户的域名下 → 上级的（海南的市县门户就在 hainan.gov.cn 下，本地和省门户同一个域名时不按域名判）。上级门户取已处理完的门户，或导航里已经认出、还没轮到处理的门户网址，结果不取决于地市、区县谁先跑完。
   - 例外：派出分局链到上级网站上分局自己的版块（如 /hbfj/xxfj/）算本区县的，链到上级部门首页的不算；开发区只认"在上级门户的域名下""外省"两种（地市开发区常以地市名打头，名称判不了归属）。
3. **门户**：下级门户名字只和外省同名的简称（"河北""海南"）不认，只认全称；政务服务网的地区页、本门户和上级门户的内页不认作下级门户；门户抓到后主机是上级门户的、或标识码和网站名都指向外省的，记"导航未找到"并写明原因，不从错的网站找部门。

被否掉的部门格记"导航未找到"，原因里写清"门户上的部门链接指向别处：「财政局」→四川省财政厅（名称以上级「四川省」开头）"，人工复核时一眼能看懂。

### 实测：天津、宁夏重跑

11/9 用新规则联网重跑天津、宁夏全省（每格 = 一个行政区 × 一个标准部门，不含政府办；"只修误配"是先只开误配修复跑的一遍）：

| 省、层级 | 格 | 找到部门：11/8 → 只修误配 → 加部门目录 | 其中有栏目：11/8 → 只修误配 → 加部门目录 |
|---|---:|---|---|
| 天津区县级 | 160 | 74 → 69 → 125 | 16 → 11 → 11 |
| 宁夏市级 | 50 | 49 → 50 → 50 | 11 → 0 → 7 |
| 宁夏区县级 | 220 | 191 → 169 → 192 | 76 → 1 → 54 |

- **只修误配**那一遍，两省 107 格的部门网址变了，逐格核对：101 格是去掉挂错的天津市、宁夏自治区、银川市部门和河北省部门（天津河北区门户改对了，tjhb.gov.cn），4 格新认出（"人力社保局"等写法），2 格是银川市局的西夏区分局版块，后来按"派出分局链到分局版块算本区县"改回、版块上银川市局菜单里的栏目不算。宁夏区县"有栏目"从 76 掉到 1，掉的几乎都是挂错的自治区厅局、银川市局的栏目。
- **加部门目录**以后，宁夏 54 格的栏目都在本县自己的网站上（各部门信息公开里的"部门文件"）。同一天早些时候用旧缓存跑出 62 格；最终代码重新联网抓一遍是 54 格，拿改动前的代码在同一份缓存上重放也是 54，差的 8 格是网站当时的页面变化，不是规则造成的；天津各区的部门在信息公开年报、指南页上认出来了（69 → 125），但部门栏目是"履职依据""规划信息"一类，没有三类栏目，照实记"已找到、网站无此栏目"。
- **全国重跑后，区县"找到部门""有栏目"的数字会先掉后涨**：挂错的格去掉，部门目录补上来，看板以重跑后的为准。

## 二、部门目录规则

### 找目录页（各平台通用，`deptdir.find_directories`）

- 从门户首页和已走过的导航页出发，沿这些链接找：直接像目录的"部门信息公开""部门街镇信息公开""区级部门信息公开""信息公开部门目录""组织机构""机构设置""政府机构"等；总入口"政务公开""政府信息公开""信息公开目录"等再进一层。只走本网站（同一个 gov.cn 域名）的链接，每个区县最多多抓 8 个页面。
- **目录页的判定**：页面上链到本网站、像机关名的链接（以局、委、办、中心等结尾）至少 6 个，其中至少 2 个是目标部门；链到文章、年报的不算（柯城区"公开指南"页上各部门链到自己的指南文章，天津各区年报页上各部门链到自己的年报）。门户首页、年报目录本身不当目录页（年报目录上的部门由盘点原有规则读"首页网址"）。
- 目录页交给盘点当导航页用：部门照常按名称认、按第一节的归属规则核对；目录页上的部门网址可以比别处深（山西县级平台的部门页在第 5 层），目录里部门页上的栏目也放宽深度（信息公开分类在第 7 层左右）。每格的导航来源页记目录页网址，可追溯。

### 每类部门选哪个页面

- 候选按分数排；同分时网站首页、栏目页排在文章、部门年报、脚本页、机构简介页前面。
- 首选能打开、但认不出能直接读的栏目时，再试后面的，最多比 3 个、最多抓 6 个页面，取第一个有能直接读的栏目的（地市一组报的杭州、常州、锦州等：部门独立网站被"组织机构"页上的门户频道、简介页顶掉）。往后只试同分的、或链接文字明写是本地的；首选本身是文章、年报、简介、公开指南页时，在本地门户自己域名下的也可以试（潍坊发改委、池州人社）。首选打不开、被拦的照旧记它，不拿分低的别的网站顶替。
- 括号里加挂的牌子（"经信局（商务局）"）也算这个机关的职能，但只当备用候选：这一类没有正名候选时才用，"科学技术局（知识产权局）"不会抢走真正的市场监管局。

## 三、怎么重跑

在 `backend/` 下：

```bash
uv run python -m youju.govsites.deptdir_trial --county 330522 --county 140426 --county 440222 --out /tmp/试读.csv --cache ~/.cache/youju-coverage-county
```

- 每个县连同它的省、地市一起走；门户网址和导航来源页取 `门户网站/<省>.csv`（11/8 官方导航的结果）。
- 全国盘点 `youju coverage-inventory` 默认对区县级找部门目录（`Inventory.deptdir_levels`）。`--levels 区县级` 只跑区县时上级不找部门，归属判断照常用名称、标识码、域名。

## 四、还没做的

   - 数字广东 gkmlpt：适配器已有（#503、#504，"政策"栏目合读见上表）；广东各市"网站无此栏目"的大头也是它，各栏目复检、抽查合格后再打开；
   - 安徽市级 public/column 平台的列表接口；
   - 网址 /content_数字 一类平台（漯河、本溪等）的列表标题混进"标题：…点击数：…发表时间：…"悬浮提示；
   - 只能 POST 的 /u/search/list/channel/by_metadata_value/网站编号（自贡、广安、资阳、开封、新余）：先记"需人工"、写明接口，适配器排后面。
2. **大汉信息公开分类接口**：拱墅区这类部门页的分组混着几个栏目，只能记信息公开分类，要按分类读列表的接口（集约化平台盘点第二节第 3 条）。
3. **一类多个子分类**：盘点每类栏目只记一个网址，"政策文件"下有几个子分类（规范性文件、其他文件）时只取条目最多的一个。数字广东已改成合读（见上表），别的平台照旧。
4. **没有三类栏目的部门**：山西黎城县、天津各区的部门栏目是"履职依据""决策信息"一类，照实记"网站无此栏目"，由政府办格兜底，核验时确认。
5. **省级统一信息公开平台**（如吉林 xxgk.jl.gov.cn）：目录页在别的域名上，这一版只走本网站，没接。
6. **请求量**：每个区县多抓目录候选页（最多 8 个）和目录里的部门页、分类栏目页，全国区县首遍估计多 1–1.5 小时。
7. **番禺区一类**：门户上先认到"机构职能"下的部门介绍页，没走到数字广东的部门页；广东区县要看是不是普遍这样，下一步一起查。
8. **几处小边角**（独立审阅第四轮的建议，11/8 清单里没碰到）：部门链接指到专题路径下频道的子页时，专题判断该按频道根目录比；独立网站链到同注册域的门户专题仍会认成部门栏目；门户链接跳到部门自己子域名的仍按门户频道处理。派出分局在大汉站上的版块（栏目都是平级的 /col/colN/）会被"只认版块目录下的栏目"滤空，只是少认。括号牌子也认"……中心"，"工业和信息化局（科技创新服务中心）"会给科技一个备用候选（只在科技没有正名候选时才用），想更稳可以排除"服务中心"。栏目页没有 ColumnName、标题第一段是部门名时往后找栏目名，"部门_子栏目_上级栏目"这种少见顺序会取到上级栏目名，可以改成只看紧跟的那一段。首选是文章、年报、简介页时，"在本地门户自己的域名下"的候选可以替换它：区县门户挂在地市域名的子域下、而地市门户又没找到时，地市部门网站会被当成本地域名（11/8 清单里 0 例）。
9. **全国重跑**：两条规则都要全国重跑盘点才生效，由全国覆盖主线排（#469 和地市一组的 PR 都合并后，按省 `--levels 区县级`）。
