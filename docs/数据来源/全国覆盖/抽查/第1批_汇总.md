## 怎么查的

1. 盘点：`youju coverage-inventory --levels 国家级 --levels 省级`（全国 31 省 + 国家级）。
2. 试读：`youju coverage-verify --level 国家级 --level 省级`：535 个栏目里能直接读的 417 个；要渲染或接口的、规则认不出的、打不开的这次都不进。
3. 试抓：417 个导入本机临时库抓一轮：415 个成功，读出 10,526 条。
4. 自动核对：`youju coverage-sample`，每个栏目核部门、栏目、条目、新鲜、本站，以及标题（代码、按钮、编号）、年报、上级文件、附件、要闻、重复；没过的逐个人工看。
5. 独立复核：另一个 Claude 只看证据表，两轮各复看每省 3 个自动通过的，并按发现的毛病扫全表。第一轮在自动通过里查出 13% 有问题（读成年报、标题是代码或按钮、转载上级文件、部门挂错），据此加了自动核对项、改了结论。

证据表：`抽查/省级/<省>.csv`、`抽查/国家级/国家.csv`。每个栏目一行，有抓取结果、最新 3 条（日期、标题、网址）、自动核对结论和人工复核三列（复核人、复核结论、复核备注）。
