## 二、这一天做了什么

盘点跑了 5 轮。第一轮全部联网（约 5,300 页），之后各轮多半用页面缓存，每轮只补抓新发现的导航页。同一网站两次请求至少隔 3 秒，透明标识，遵守 robots。"有栏目"的格从 1,080（广东 0）涨到 1,274（广东 75）。改动全在导航这一层（主线分给这条线的文件）：

| 改动 | 补上的地方 |
|---|---|
| 首页只有跳转脚本、地址放在变量里或带条件的，跟到电脑版：按设备分（南京）、换 https（徐州）、按主机名分（益阳）。`'9103'=='9102'` 这种不成立的条件照旧不跟 | 南京、益阳 |
| 菜单名是"市直部门""政府部门""县区政府"的链接脚本，按菜单名挑（原来只按文件名挑，安徽各市有几十个 `ljgl` 脚本，轮不到） | 芜湖、马鞍山、宿州、六安、黄冈：约 50 格 |
| 地市门户上的部门列表页：部门频道、市政府工作机构、机构职能、市政府部门、市直部门、政务公开 | 遂宁、周口、荆州等 |
| 官方导航给的 http 地址连接被断开、同一网站 https 能打开的，改取 https（403、412、521 照旧记不能抓，不换标识） | 广东省门户（21 个地市原来一个都没找到）、福州、盘锦 |
| 导航词"州市"不再误认"杭州市稳岗就业"一类链接：名字带"州"的城市首页，导航名额原来被这类链接占满 | 名字带"州"的城市 |
| 上级网站链到下级门户的年报页、文章页时，取网站首页 | 临沂、保定 |
| 跳转包装链接（`loading.html?from=名称`，看不出指向哪里）不当链接用 | 东莞（原来 10 个部门错记"不能抓"） |
| `/dept/<编号>.html`、`/columns/<编号>/` 是频道页，不是文章 | 遂宁、石家庄 |
| 行政区写法补"××自治州"（湖南省门户写"湘西自治州"） | 湘西州 |

补充导航页上找到的部门不加分，不顶掉原有导航找到的部门网站。第二轮杭州的部门网站被门户里的部门频道顶掉过，这样改了以后就没再出现。

抽查工具：`python -m youju.govsites.spotcheck`（`govsites/spotcheck.py`）。按固定种子抽格；取政府网站上的网页核对，外链和附件不核，原文打不开就顺延下一份。标题去掉截断、标点后比对；日期认网页头的 PubDate、"发布日期/发布时间/信息时间"，正文里"询价公告发布日期""公示时间"一类不算；归属看网站名、标题、发文单位和门户域名。程序判"待人工看"的，由 Claude 逐条打开原文看过、签字；每省第 1 条留给创始人复看（13 条，约 5%）。

## 四、抽查发现的数据问题

13 省抽 260 格，合格 247 格（95%）。不合格的 13 格有三类：

1. **标题被污染**（漯河 4 格、本溪 1 格）：两地用的同一种平台，列表上有悬浮提示，库里标题混进了"标题：…点击数：…发表时间：…"。这种平台的所有栏目都会这样，要改列表识别（`crawler/listing.py`），归主线。
2. **日期是转载日期**（安阳、许昌、攀枝花、益阳、咸宁、沈阳工信，共 6 格）：部门栏目转载上级或别的单位的文件，列表上的日期比原文晚几天到一年。库里记的是列表日期，用户看到的发布日期就会偏晚。要不要按原文日期记，归主线定。
3. **归属或原文不对**（枣庄数据局、盘锦发改委）：
   - 枣庄"数据局"一格挂的是市政府的"财政预决算公开"专题，属于误配，已转区县规则线；
   - 盘锦发改委一格的文件链到省招标投标监管网的脚本页，原文核不了。

另外，栏目里转的新华网、微信公众号外链也照收进了库（淮北市场监管、滨州数据局）。抽查时跳过了这些外链，没算不合格；进不进库，归主线定。
