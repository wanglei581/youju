# 政府网站集约化平台盘点（每省，2026-11-08）

目的：弄清每个省的部门、市、县网站是不是建在同一个平台上、列表能不能直接读、有没有防护，从而定下每省用哪一套（或几套）读取规则。目标是 **30–50 个适配器管全国**，而不是给 1.7 万个网站各写一份配置。

数据来自两处，都可以重跑：

- 全国盘点（`youju coverage-inventory`）：每个门户和部门网站页面的平台特征——网站标识码、页脚"技术支持"、平台标记（大汉 datastore/jpaas、拓尔思 createPageHTML 等）、文章网址形状（`/art/2026/11/5/art_123_456.html`、`/t20261105_123.html`、`/post_123.html`……）；
- 抽样试读（`youju coverage-verify --sample-per-level 8`）：每省每级抽 8 个栏目，用正式抓取程序的列表识别（含平台适配器）读一遍。

程序生成的明细（每省各平台的网站数、代表网址、抽样结果）在 `集约化平台盘点_数据.md`；抽样的每个栏目在 `栏目抽样试读/<省>.csv`。

## 一、全国结论

1. **两大平台占大头**：拓尔思（静态分页 `index_1.html`，网址 `t日期_编号`）和大汉（老版 JCMS 的 datastore、新版 jpaas 单元接口，网址 `art_日期_编号`）。其次是开普云、广东集约化（`post_编号`）、安徽的前端渲染平台、黑龙江的自有平台。几个省一个平台占 80% 以上（浙江 100%、吉林 100%、重庆 99%、贵州 99%、宁夏 98%，按盘点找到的网站算）——这些省的技术架构统一，同一套规则可以复用，但县级仍有部门目录、分组列表等变体要分批适配。
2. **列表能直接读的多**：全国抽样 590 个栏目，正式抓取程序（通用规则 + 大汉 jpaas 适配器）直接读出带日期条目的 433 个（73%）；要脚本渲染或接口的 99 个（17%），集中在上海、安徽、广东、浙江县级（信息公开分类）、重庆；通用规则认不出的 33 个（6%）；打不开 23 个（新疆县级为主）、被拒 2 个。
3. **防护集中在几个省**：412/521 防护页（瑞数、加速乐类）——湖北、甘肃省级门户，湖南 11 个县级门户，安徽 14 个部门网站；403 拒绝——吉林 9 个县级门户和 7 个部门网站、河南 7 个门户；robots 禁止——陕西 11 个县级门户、辽宁 10 个、北京 3 个区。一律记"不能抓"，不绕过，另找替代来源。
4. **5 个省的省级门户本身不通**：江西（robots.txt 取不到，502）、广西（连接被断开）、海南（加密连接中断）、湖北、甘肃（412 防护）。这 5 省的地市、区县这次一个都没从官方导航找到，要另找官方入口（见第四节）。新疆 11/5 也连不上，11/8 用同样的透明标识重试后能访问了，说明一部分"打不开"是暂时的。
5. **最大的缺口在县级部门目录**：县直部门多半没有独立网站，藏在门户的信息公开平台里，部门列表、按部门筛选的列表都由平台脚本生成。按平台写"部门目录"规则是第二阶段县级铺开的主要工作量（试点报告第三节）。

## 四、省级门户不通的 5 个省怎么办

规矩不变：只用透明标识，不换标识、不绕过防护。

1. **先确认是不是暂时的**：江西（502）、海南（加密连接中断）在不同时段各重试几次，记录每次结果（新疆就是这样恢复的）。
2. **确属拒绝的记"不能抓"**：湖北、甘肃（412 防护页）、广西（以往就拒绝爬虫标识，见 `../说明.md`）。
3. **地市、区县门户另找官方入口**：地市门户本身通常能访问，入口从这些官方页面找——已能访问的兄弟省份门户里的"地方政府网站"导航（如中国政府网只列到省）、地市门户自己的"兄弟城市""省内各市"导航、省政务服务网的地区导航页。找到的入口写进导航入口补充表并注明来源页，仍然可追溯。
4. **省级部门**：省直部门网站多数是独立域名（如 kjt.xxx.gov.cn），不受省门户防护影响的可以从部门互链、年报、上级部委"地方链接"找到。

## 五、怎么重跑

在 `backend/` 下（页面缓存 14 天内不重抓）：

```bash
uv run youju coverage-verify --state ~/.cache/youju-coverage/state-全国.json --sample-per-level 8 --retry-failed
```

```bash
uv run youju coverage-survey --state ~/.cache/youju-coverage/state-全国.json --checks ~/.cache/youju-coverage/checks-抽样-全国.json
```

注意：并发高时系统域名解析偶尔会回"找不到"，盘点工具已经对解析失败重试三次；一次跑完后用 `--retry-failed` 把失败的页面再抓一遍，"打不开"才可信。
