# 小程序备案操作单（创始人用，2026-10-04）

> 用途：在小程序后台提交“小程序备案”（ICP 备案）。**没有备案号小程序不能发布**，这是现在上线的关键一步。
> 依据：微信官方《小程序备案指引》《小程序备案材料示例》《小程序备案常见问题》《服务内容选择指引》《短信核验》（developers.weixin.qq.com/miniprogram/product/record…）。Grok 10/4 检索，Claude 本机取回原文核对了下面标“已核对”的条目。

## 一、先确定三个人（山东规则，已核对）

| 角色 | 山东企业的规定 | 怎么填 |
|---|---|---|
| **主体负责人** | **必须是法定代表人**（山东“非政府机关、事业单位”一栏），不能用授权书代替 | 填营业执照上的法定代表人；姓名和执照不一致会被提示“请重新填写，并保持一致” |
| **小程序负责人** | 可以不是法定代表人，**不需要授权书** | 建议填**小程序管理员**本人，并用管理员的微信做人脸核验（官方说填写人和扫码微信的实名不一致会“实名验证失败”） |
| 应急联系人 | 按页面要求填 | 手机号要本人在用 |

- 手机号、邮箱：**不同人不能共用**；要本人在用、保持畅通。
- 法定代表人要能按时接收工信部短信（号码 12381）并在 **24 小时内**登录 beian.miit.gov.cn 完成核验，超时自动退回。提交前先跟法定代表人约好时间。

## 二、要准备的材料

1. 营业执照（原件拍照或彩色扫描，**有效期大于 3 个月**）。
2. 法定代表人身份证（同样要求）。
3. 小程序负责人身份证。
4. 人脸照片在平台现场拍；承诺书、真实性核验单由平台提供，在平台确认。
5. 前置审批：我们只做“信息查询”，不涉及新闻、金融、医药等需要前置审批的内容，**不用交**。如果单位名称或经营范围里出现前置审批相关的关键字，平台可能要求签一份“普适版不涉及前置审批承诺书”，按提示签即可。

## 三、小程序信息怎么填（已核对）

- **服务内容**：选“工具 → **信息查询**”（官方：“适用于提供信息查询、订单功能等服务”，可选，需符合单位经营范围）。
- **不要选**：“时政信息”（官方写“不建议选择”）、“政务民生”（非政府单位不得选）、新闻资讯类。
- **名称**：不要带金融、医药、新闻等前置审批领域的词；名称要在单位经营范围之内。
- **简介和备注**：如实写“整理政府官网公开发布的申报通知和认定、公示名单，提供检索、截止日期提醒和名单查询；第三方工具，不是政府平台”。和类目“工具 > 信息查询”、营业执照经营范围对得上。

## 四、流程和时间（已核对）

1. 小程序后台 → 设置 → 小程序备案 → 去备案（未上架的新小程序也可以备案）。
2. 平台初审：1–2 个工作日。
3. 初审通过后 5–10 分钟内收到 12381 短信，**24 小时内**完成核验。
4. 通信管理局审核：1–20 个工作日。
5. 下发备案号；小程序发布后备案号会自动显示在“更多资料”页。
6. 被驳回：小程序后台首页 → 小程序备案 → 查看驳回原因；修改后再提交，平台约 7 个工作日。

## 五、常见退回原因（官方写明的）

- 主体负责人和法定代表人不一致（山东企业必须一致）。
- 名称与经营范围不匹配，或名称涉及前置审批领域。
- 服务内容和主体经营范围、资质不符。
- 从事新闻等需要前置审批的业务，却没交审批文件。
- 手机号或邮箱多人共用；短信 24 小时内没核验。

## 六、备案号下来以后

告诉团队备案号，团队更新“关于有据”页和提审材料，然后按 [真机验收操作单](../迭代/真机验收操作单_R1.md) 做验收、提交审核。
