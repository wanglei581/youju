# 虚拟支付开通操作单（创始人用，2026-10-04）

> 用途：开通微信“小程序虚拟支付”、把支付后台接到线上，先在**沙箱**里跑通，再决定何时对用户打开。
> 依据：微信开放文档《小程序虚拟支付》接入指引、`wx.requestVirtualPayment`、《技术服务费》，微信云托管《开放接口服务》《消息推送》。Claude 10/4 用本机取回官方原文核对。
> 前提：D-050（省通管局已确认免许可证）。支付代码在草稿 #145，**合并、发布之前不用做第 5–7 步**；第 1–4 步现在就可以做。
> 密钥（AppKey、AppSecret）只由创始人填进云托管环境变量，不发给任何人，也不要截图。

## 第 1 步：开通虚拟支付（小程序后台）

1. 登录小程序后台（mp.weixin.qq.com），左侧点 **虚拟支付** → **开通**，签署协议、上传商户资料。
2. 开通条件：已认证的小程序；主体是企业；主体信息完备。
3. 约 1–2 个工作日后，状态显示“已签约”或进入了商户管理模块，就是开通成功（会新开一个微信支付商户号）。

## 第 2 步：苹果手机要用，配置小程序简称

虚拟支付 → 基础配置 → 配置**小程序简称**（苹果支付要求显示名称）。不配，苹果手机上付不了款。

## 第 3 步：配置商品（道具）

在虚拟支付的商户管理后台 → **道具管理**，新建两个道具，**先发布到开发版本**（沙箱用），以后再发布到现网版本：

| 道具 ID | 名称（建议） | 价格 |
|---|---|---|
| `compare_100` | 名单比对 100 家以内 | 访谈后定（定价方案区间 19.9–49 元） |
| `compare_200` | 名单比对 200 家以内 | 访谈后定 |

- 道具 ID 要和上面一字不差（后台按这个 ID 下单）。
- 发布后约 10 分钟生效。
- 费率（工具类目，当前生效）：安卓、鸿蒙、电脑版 1%；苹果手机 12%（全部是苹果佣金），月末后 45–60 天到账。

## 第 4 步：记下基础配置

虚拟支付 → 基本配置 → 基础配置，能看到 **OfferId**、**沙箱 AppKey**、**现网 AppKey**。OfferId 可以告诉团队；两个 AppKey 只填到第 6 步的环境变量里。

## 第 5 步：云托管开放接口服务（支付代码发布前做）

微信云托管控制台 → api 服务 → **开放接口服务**：

1. 打开开关。
2. 在接口权限列表里加上：`/xpay/query_order`、`/xpay/refund_order`、`/xpay/notify_provide_goods`、`/xpay/download_bill`、`/xpay/download_ios_settlement_bill`、`/sns/jscode2session`。
3. 开启后要**重新构建一次版本**才生效（团队发布新版本时自然满足）。

## 第 6 步：环境变量（api 服务；支付代码发布时做）

| 变量 | 填什么 | 说明 |
|---|---|---|
| `YOUJU_PAY_ENABLED` | `false` | 先保持关闭；沙箱测试时临时打开，测完关上；对用户打开要等 D-046 门槛达标、创始人批准 |
| `YOUJU_XPAY_OFFER_ID` | 第 4 步的 OfferId | |
| `YOUJU_XPAY_ENV` | `1` | 1 = 沙箱，先用沙箱；正式收费时改成 0 |
| `YOUJU_XPAY_APPKEY_SANDBOX` | 沙箱 AppKey | **密钥，只填这里** |
| `YOUJU_XPAY_APPKEY_PROD` | 现网 AppKey | **密钥，只填这里**；正式收费前再填也可以 |
| `YOUJU_XPAY_PRICE_100` / `YOUJU_XPAY_PRICE_200` | 道具价格，**单位是分**（19.9 元填 1990） | 必须和第 3 步道具价格一致，否则下单报错；不填就不开放该档 |
| `YOUJU_WX_APPID` | 小程序 AppID | 不是密钥 |
| `YOUJU_WX_APPSECRET` | **先不填** | 只有线上试出“开放接口服务换不到 session_key”时，才由创始人自己填（团队不经手） |

## 第 7 步：消息推送（支付代码发布后做）

微信云托管控制台 → 设置 → 全局设置 → **消息推送**：

1. 环境选我们的环境；服务选 **api**；path 填 `/api/wx/push`；格式 JSON。
2. 用小程序管理员的微信扫码确认。
3. 微信会发一个检测请求，后台会自动应答成功。
4. 注意：一个小程序的所有消息推送都会发到这个路径；以前如果在开发者后台配过“服务器地址”，会被覆盖。

## 第 8 步：数据库授权（迁移 0026 执行后）

执行 `backend/deploy/mysql_accounts.sql` 里“支付权限”那两行（给 `youju_api` 加 `pay_orders`、`pay_events` 的写权限）。团队发布时会提醒。
