## 已经完成的（不用再做）

- 第 1 步开通虚拟支付：你 10/16 告知已开通（同时开通了微信支付）。普通微信支付不能用于小程序里的虚拟商品，这次用不上。

## 第 2 步：配置小程序简称（苹果手机要用）

虚拟支付 → 基础配置 → 配置**小程序简称**。不配，苹果手机上付不了款。

## 第 3 步：建道具「客户工作台 30 天」

虚拟支付的商户管理后台 → **道具管理** → 新建一个道具，**先只发布到开发版本**（沙箱用）：

| 道具 ID | 名称 | 价格 |
|---|---|---|
| `workbench_30d` | 客户工作台30天 | 29 元（D-058 起步价；访谈后要改就同时改这里和第 6 步的价格） |

- 道具 ID 一字不差；发布后约 10 分钟生效。

## 第 4 步：记下基础配置

虚拟支付 → 基本配置 → 基础配置：**OfferId** 可以告诉团队；**沙箱 AppKey**、**现网 AppKey** 只填到第 6 步。

## 第 5 步：云托管开放接口服务（api、admin 两个服务都要）

微信云托管控制台 → 服务 → **开放接口服务** → 接口权限列表加上：`/xpay/query_order`、`/xpay/refund_order`、`/xpay/notify_provide_goods`、`/xpay/download_bill`、`/xpay/download_ios_settlement_bill`、`/sns/jscode2session`。
admin 每分钟补单、退款、每天对账也要调这些接口，所以两个服务都加。开启后要重新发布一次版本才生效（团队发布时自然满足）。

## 第 6 步：环境变量（api、admin 两个服务都填同样的值）

| 变量 | 填什么 | 说明 |
|---|---|---|
| `YOUJU_PAY_ENABLED` | `true` | 只在沙箱联调期间打开；联调完可改回 `false`。打开后**默认只对测试名单开放** |
| `YOUJU_PAY_AUDIENCE` | `whitelist` | 一定保持 `whitelist`。对全体收费时才改成 `all`（要你另行批准） |
| `YOUJU_PAY_OPENIDS` | 测试人员的 openid，逗号分隔 | 测试人员在小程序「我的 → 我的数据」里点「复制完整标识」发给你（没有这一行时点「复制全部数据」，里面 user 下的 openid 就是）；和 AI 内测白名单是同一个标识 |
| `YOUJU_XPAY_OFFER_ID` | 第 4 步的 OfferId | |
| `YOUJU_XPAY_ENV` | `1` | 1 = 沙箱。正式收费时改成 0 |
| `YOUJU_XPAY_APPKEY_SANDBOX` | 沙箱 AppKey | **密钥，只填这里** |
| `YOUJU_XPAY_APPKEY_PROD` | 现网 AppKey | **密钥，只填这里**；正式收费前再填也可以 |
| `YOUJU_XPAY_PRICE_PASS` | `2900` | 单位是分，必须和第 3 步道具价格一致，否则下单失败；不填就不卖 |
| `YOUJU_PAY_TERMS_VERSION` | 先不填 | 沙箱联调不用填。律师定稿《付费服务协议》后由团队告诉你填什么；正式收费（`YOUJU_XPAY_ENV=0`）时不填就不卖 |
| `YOUJU_WX_APPID` | `wxcf20754e505e9bfa` | 不是密钥 |
| `YOUJU_WX_APPSECRET` | **先不填** | 只有线上试出「开放接口服务换不到 session_key」时才由你自己填 |

改环境变量会生成一个新版本（备注 server config change）。改完告诉团队，团队用只读工具核对新旧版本的流量和实例。

## 第 7 步：消息推送（发货推送要用）

微信云托管控制台 → 设置 → 全局设置 → **消息推送**：环境选我们的环境；服务选 **api**；path 填 `/api/wx/push`；格式 JSON；用小程序管理员微信扫码确认。微信会发检测请求，后台自动应答成功。
一个小程序的所有消息推送都发到这个路径。

## 第 8 步：数据库授权（团队发布了迁移 0030 之后）

执行 `backend/deploy/mysql_accounts.sql` 里「支付权限」那四行（`pay_orders`、`pay_events`、`workbench_passes`、`invoice_requests` 的写权限）。团队发布时会提醒你。

## 沙箱联调怎么验（团队给步骤，你用安卓手机点）

1. 测试人员用**安卓手机**打开体验版：工具表单用完免费次数后出现「客户工作台 30 天（29 元）」→ 进购买页 → 勾选协议 → 付款。沙箱环境（`YOUJU_XPAY_ENV=1`）下购买页顶部写着「沙箱测试，不扣真钱」，协议没定稿也能点付款；现网（`0`）必须律师定稿协议后付款按钮才可用。
2. 回到页面应显示「已开通，使用期到 ××」；「我的 → 我的订单」能看到这笔订单。
3. 7 天内、没用过付费额度时点「申请退款」，确认钱原路退回、使用期取消。
4. 另买一笔，在订单页「申请发票」填抬头和邮箱；团队在管理台「开票」里看到申请。
5. 非测试名单的微信号同时打开小程序：不应看到任何购买入口、价格或「我的订单」。

苹果手机：官方不支持沙箱，只能在正式收费时用现网真付款验证一次（金额 29 元，苹果手机不能由我们主动退款）。
