# 首期开发执行清单

## 本次任务合同

目标：在本仓库建立能由微信开发者工具打开的原生小程序项目，并连通本地受控试用 API；后台能登记来源、预览导入、审核发布；用户能查询已发布资料、查看证据与来源、选择结果导出 XLSX/DOCX。

边界：不宣称全行业覆盖；不自动抓取无权资料；没有证据不输出确定答案；不实现付费、公开 AI 问答或线上部署。真实来源许可和小程序主体能力尚未核准时，以人工导入与本地试用为限。

验收证据：

1. 微信开发者工具可导入 `apps/miniapp/`，四栏页面可打开，空、错、加载状态明确。
2. 管理端能够走通来源登记→CSV/XLSX 预览→提交待审→发布；未发布资料对公开接口不可见。
3. 小程序能查询已发布资料、显示题录/证据权限区别、选择结果并取得两种格式文件。
4. 服务端用自动化检查验证未审隔离、仅题录权限、修订与撤回、导出选择与错误行为。
5. 本地接口与小程序模拟器各做一次操作验证；真机、线上来源、支付和公开 AI 另有独立证据门槛。

## 责任与顺序

- Codex：仓库与 API 审查、集成、测试、开发工具验证及最终证据。
- Claude：`apps/miniapp/` 前端主实现；同一工作树内由 Claude 写入时其他角色只读。
- agy：架构和页面/流程一致性审查，只读。
- Grok：安全与验收缺口审查，只读。

本清单是开发执行记录，不替代用户批准发布、来源授权或商业验收。
