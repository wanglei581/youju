# 有据

「有据」（小程序全称"有据申报与行业助手"）：面向全国、覆盖全行业的 AI 行业情报助手。政策、申报通知、认定名单、行业数据和报告线索，每条都能点回官方原文；有变化自动提醒；一键导出 Excel/Word/PPT。

项目目录名"行业政策"是内部代号，上线名称为「有据」（商标和小程序重名待创始人确认，见[决策记录 D-008](docs/决策记录.md)）。

## 目录

- `apps/miniapp/`：微信原生小程序（四栏骨架）。
- `backend/`：当前后端与 API，见[后端 README](backend/README.md)；早期 SQLite 样机已于 2026-10 移除。
- `docs/`：总方案、执行手册、决策记录、数据来源、调研记录。
- `designs/产品原型/`：可点击的交互原型，使用明确标注的虚构样例。
