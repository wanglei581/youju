# 行业政策

面向职场人的行业资料与政策查询小程序。用户先看到有出处的结果，再按需查看来源、关注变化并导出所选资料；资料由后台审核后发布。

## 当前开发范围

本仓库从受控试用版开始，不代表全行业资料已接入。当前目标是完成一条可验证的路径：登记来源及可用动作 → 导入 CSV/XLSX → 审核发布 → 微信小程序查询和查看证据 → 选择结果导出 XLSX/DOCX。来源自动监测、公开 AI 问答、支付、外部应用投递与跨行业报告按规划分期接入。

- `apps/miniapp/`：微信原生小程序。
- `services/api/`：本地开发 API 与资料管理台。服务端代码源自上一轮未验收草稿，迁入后必须重新审查和测试。
- `docs/`：需求、主规格与开发输入。
- `designs/产品原型/`：可点击的前台与后台交互原型，使用明确标注的虚构样例。

## 状态

开发中。当前没有生产数据、用户、支付或线上服务。不要把本地运行视为正式上线或商业验收。

主要规划见[需求分析与项目规划](docs/全行业资料库小程序_需求分析与项目规划_v1.md)及[产品主规格](docs/全行业资料库AI小程序_完整产品与开发主规格_v5.1.md)。

小程序导入与本地启动步骤见[小程序 README](apps/miniapp/README.md)。原型可通过 `python3 -m http.server 4311 --directory designs` 后访问 `http://127.0.0.1:4311/产品原型/行业政策_小程序交互原型.html`。
