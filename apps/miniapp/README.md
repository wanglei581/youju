# 微信小程序本地试用

这是原生小程序源码。项目暂未绑定 AppID；当前机器上的微信开发者工具 CLI 对空 AppID 和游客标识均返回“不存在此 AppID”，因此尚未取得模拟器编译证据。取得本项目的有效 AppID 后，再导入本目录并验证。正式发布还需配置服务域名与相关平台能力。

## 本地启动

早期 SQLite 样机已于 2026-10 移除。当前后端的启动与管理台使用方式见[后端 README](../../backend/README.md)。

将本项目的有效 AppID 填入 `project.config.json`，在微信开发者工具中导入 `apps/miniapp/` 并编译。正式发布还需按当前后端配置服务连接。

## 当前功能边界

- 查询/详情只读服务端已发布资料；仅题录来源不会显示被限制的答案或摘要。
- “关注”仅在本机保存条件，点“检查更新”时手动比对服务端前 50 条结果；不代表来源自动监测，也没有微信推送。
- Excel/Word 由本地 API 生成，小程序保存在本机文件空间并尝试打开；文件历史只在本机。Office/WPS 与真机交付路径尚需单独验收。
- 无公开 AI 问答、账号、付费、跨行业报告、PDF/PPTX 或外部工作应用连接。没有真实来源许可和平台审核前，不可上线对公众使用。
