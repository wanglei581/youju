# 公众号栏目封面

四个栏目各一张固定封面：申报周报、临期提醒、名单速报、使用说明（[搭配方案](../../docs/商业/公众号与小程序搭配方案_2026-10-18.md)第四节第 4、5 条）。每期用同一张，日期和期号写在文章标题里，每期不用改图。

| 栏目 | 封面（上传这张） | 1:1 预览（就是正中那一块） |
|---|---|---|
| 申报周报 | `封面/申报周报_2.35比1.png` | `封面/申报周报_1比1.png` |
| 临期提醒 | `封面/临期提醒_2.35比1.png` | `封面/临期提醒_1比1.png` |
| 名单速报 | `封面/名单速报_2.35比1.png` | `封面/名单速报_1比1.png` |
| 使用说明 | `封面/使用说明_2.35比1.png` | `封面/使用说明_1比1.png` |

同名的 `.svg` 是源文件（文字已转成路径、logo 已内嵌，换台电脑打开也一样）。

## 怎么用

1. 写文章时在"封面"里上传对应栏目的 `_2.35比1.png`（1880×800）。第一次上传后它会留在图片库里，以后直接从图片库选。
2. 微信会让你从这张图里裁两块：**2.35:1 选整张；1:1 放在正中**（左右各空出 540 像素，图标块和栏目名正好在正中的方块里）。官方草稿接口也是这样：一篇文章一张封面图，两个比例各给一个裁剪框（[新建草稿接口](https://developers.weixin.qq.com/doc/service/api/draftbox/draftmanage/api_draft_add.html)的 `cover_info.crop_percent_list`，文档写明"图文消息（news）和图片消息（newspic）均适用"，2026-10-18 核对；旧版文档里叫 `pic_crop_235_1`、`pic_crop_1_1`）。以后用接口把文章放进草稿箱时，裁剪坐标照填：2.35:1 取 (0, 0)–(1, 1)，1:1 取 (0.287234, 0)–(0.712766, 1)。
3. 2.35:1 用在订阅消息列表的大图；1:1 用在转发给好友和群的卡片、多篇一起发时第二条以后的小图。`_1比1.png` 就是正中那一块，用来预览裁出来的样子。

**为什么封面上不放日期和期号**：标题里已经有日期（方案第四节"标题写法"），订阅消息和转发卡片都会把标题和封面一起显示；封面固定，创始人每期不用改图，读者看颜色和图标就认得是哪个栏目。以后想要带日期的版本，在 `生成脚本/covers.py` 里加一行文字即可，但那样每期都要重新出图。

**为什么封面上不写"第三方整理"**：按要求封面不放小字。"第三方整理，非政府平台，以原文为准"写在每篇正文第一行和文末（方案第四节第 5 条），简介里也有。

## 设计

和小程序"风格 C 精修版"（[D-014](../../docs/决策记录.md)）一致，读者在公众号和小程序里看到的是同一套东西：

- **底色**：小程序首页顶部的品牌蓝渐变，上 `#2F66F0`、下 `#2553D6`。
- **左上角**：logo + "有据"，位置同小程序首页顶部的品牌名。只在 2.35:1 里出现；1:1 的转发卡片下方本来就带公众号头像和名称。
- **正中（就是 1:1 的画面）**：小程序首页入口同款的渐变图标块（84:26 的圆角比例、145° 渐变）+ 栏目名。
  - 申报周报：蓝色块 + 日历；
  - 临期提醒：绿色块 + 沙漏，和小程序首页"截止"入口一样；
  - 名单速报：橙色块 + 列表，和小程序首页"查名单"入口一样；
  - 使用说明：浅色块（小程序页面底色 `#F2F4F8`）+ 品牌蓝的说明图标（圆圈 i，和小程序"关于有据"一样）。不用蓝色块，是为了和申报周报区分开，缩成转发卡片的小图也认得出。
- **字**：栏目名 148 像素（字距 0.04 em），"有据" 64 像素，思源黑体（Noto Sans SC）中粗 500，白色。封面上没有比这更小的字。缩成转发卡片里 48pt 的小图时，栏目名约 9pt、图标约 8pt。
- **图标块**：236 像素见方、圆角 73 像素，图标占 58%；阴影很淡（下移 6、模糊 10、不透明度 0.15），彩色块内侧一圈 2 像素、20% 的白边，让蓝色块在蓝底上看得清。
- **不用**：图库照片、AI 配图、印章和国徽一类元素、"官方"字样、小字说明。

尺寸按 2 倍图出：2.35:1 是 1880×800（微信建议 900×383），1:1 是 800×800，PNG 每张约 45–95 KB。`预览_手机上的样子.png` 是按手机实际比例排的示意（订阅消息大图、转发卡片小图；界面是示意，不是微信的真实界面）。

## 重新生成

改颜色、字号或栏目，改 `生成脚本/covers.py` 后重新生成（需要本机装有 Chrome）：

```bash
python3 -m venv /tmp/cover-venv && /tmp/cover-venv/bin/pip install fonttools brotli pillow
/tmp/cover-venv/bin/python designs/公众号/生成脚本/covers.py --font <Noto Sans SC 500 字重> --logo <主目录>/designs/品牌/有据-logo-v1.png --out designs/公众号/封面
/tmp/cover-venv/bin/python designs/公众号/生成脚本/render.py designs/公众号/封面/*.svg
cd designs/公众号/生成脚本 && /tmp/cover-venv/bin/python preview.py --font400 <400 字重> --font500 <500 字重> --logo <logo> --out ../预览_手机上的样子.png
```

`covers.py` 会检查栏目名完整落在正中的方块里（1:1 裁出来不会切字）；栏目名超过 4 个字要先缩字号。
