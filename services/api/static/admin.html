资料管理台

先确认来源使用范围，再导入题录与证据。每次导入形成待审版本；只有人工发布的版本才对用户可见。

管理身份

本地试用版使用服务端令牌

① 登记来源

资料用途逐来源登记。默认“仅题录”；开放摘要或答案须填写审核依据。

② 导入资料

CSV 使用 UTF-8；XLSX 使用第一张表。一次最多 500 行。上传后先预览，提交后仍是待审版本。

③ 审核与发布

逐条打开原站核验。新导入不会直接覆盖现有公开版本；确认发布后才切换。

本地管理台不等于生产权限系统。正式上线需要具名审核人、角色权限、操作审计、备份与资料授权复核。
